# 0-2 はじめての一文字

## 場面

メモの最後の行では、名前の欄が「？？？」のまま空いています。

イコちゃん「このフォルダは、ゲンさんの整備工場と共有されているようです。名前を書いておけば、ゲンさんが読んでくれるかもしれません」

ただし、エディタで文字を書き換えただけでは、フォルダの中のファイルは変わりません。書き換えたら保存して、動かして確かめる必要があります。

イコちゃん「名前と、ゲンさんへのあいさつを書いてみましょう」

## 今回の目標

メモの「？？？」を自分の名前に書き換え、コンソールにあいさつを出します。「書き換える、保存する、動かす」の流れを覚えます。

## 手順

### 1. 名前を書き換える

ファイルの一覧で `index.html` を選びます。10 行目の「？？？」を消して、自分の名前を書きます。名前はニックネームでもかまいません。

手本では「ミナの友だち」と書きます。ミナは、このあとの課で出てくる人です。

```html
  <p>このフォルダを開いた人の名前: ミナの友だち</p>
```

`<p>` と `</p>` の印は消さずに、間の「？？？」だけを書き換えます。

### 2. 保存して動かす

「保存」を押します（Ctrl+S）。保存していない書き換えがあるファイルは、ファイルの一覧で名前の後ろに `*` が付きます。保存すると、`*` が消えます。

続けて「動かす」を押します（Ctrl+Enter）。プレビューの最後の行に、書いた名前が出れば正しくできています。

### 3. あいさつの行を足す

12 行目の `console.log` の行の終わりで Enter を押し、新しい行を作ります。作業場は、前の行と同じ深さの字下げを自動で入れます。その行に、あいさつを出す命令を打ちます。

```html
  <script>
    console.log('夕暮れ峠のフォルダが開かれました');
    console.log('こんにちは、ゲンさん');
  </script>
```

あいさつの文は変えてもかまいません。ただし「こんにちは」の文字は必ず入れます。答え合わせで、この文字を確かめるからです。

`(` `)` `'` `;` は、半角で打ちます。日本語入力のまま打った `（` や `’` が混ざると、あいさつは出ません。

### 4. もう一度保存して動かす

保存して動かします。コンソールに次の 2 行が出れば、正しくできています。

> 夕暮れ峠のフォルダが開かれました
> こんにちは、ゲンさん

コンソールに誤りを知らせる行が出たときは、3 の手順で打った行に全角の文字がないかを見直します。

## しくみ

### 保存

エディタで書き換えた文字は、保存するまでフォルダのファイルには書き込まれません。保存すると、`/プロジェクト/夕暮れ峠/index.html` の中身が新しくなります。書き換えたら、こまめに保存します。

### タグ

`<p>` や `</p>` のように、`<` と `>` で囲んだ印をタグ（tag）と呼びます。`<p>` から `</p>` までの文は、1 つの段落としてプレビューに表示されます。タグのくわしい決まりは、次の課から学びます。

### JavaScript と console.log

`<script>` と `</script>` の間には、JavaScript（ジャバスクリプト）というプログラムの言葉を書きます。HTML はページの中身を書く言葉です。JavaScript は、ページの中で動く手順を書く言葉です。

`console.log( )` は、かっこの中の値をコンソールに出す命令です。行の終わりの `;`（セミコロン）は、命令の区切りを表します。

`'こんにちは、ゲンさん'` のように、`'` で囲んだ文字の並びを文字列（string）と呼びます。`'` で囲まないと、ブラウザは日本語の文字を命令の名前として読もうとして、誤りになります。

JavaScript では、大文字と小文字も区別します。`Console.log` と書くと誤りになります。JavaScript は、第 3 部でくわしく学びます。

## 答え合わせ

「答え合わせ」を押すと、次の項目を確かめます。

- 「？？？」を自分の名前に書き換えた
- コンソールに「こんにちは」と出している

通らないときは、保存して動かしてから、もう一度「答え合わせ」を押します。どこが違うか分からないときは、「手本との違い」で手本と違う行を見られます。名前の行は、手本と違っていてかまいません。

## 変えてみよう

### 1. 峠の長さを計算する

夕暮れ峠の全長は 1,981 m です。km に直した値を、コンソールに出してみましょう。1 km は 1,000 m です。

:::answer
あいさつの行の次に、次の行を足します。

```js
    console.log(1981 / 1000);
```

コンソールに `1.981` と出ます。数は `'` で囲まずに書きます。`/` は割り算の記号です。数の中に `,` は入れません。`,` は、値と値の区切りの記号として扱われます。計算は、第 3 部でくわしく学びます。
:::

### 2. 段落を 1 つ足す

名前の行の次に、好きな色や好きな車を書いた段落を足してみましょう。

:::answer
```html
  <p>このフォルダを開いた人の名前: ミナの友だち</p>
  <p>好きな色: 夕焼けのオレンジ</p>
```

`<p>` と `</p>` ではさんだ文が、新しい段落として表示されます。
:::
