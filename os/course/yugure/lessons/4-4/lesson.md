# 4-4 曲がる・止まる

## 場面

今の車は、止まったままでもその場で回ります。ブレーキもありません。
ゲンさんが、工場の机に紙を 1 枚広げました。
ゲンさん「車は、動いていないと向きを変えられない。速すぎても、思ったほどは曲がれない。タイヤが横へ滑り出すからだ」
ミナ「じゃあ、速いときはどうやって曲がるの？」
ゲンさん「大回りになるのさ。だから、ブレーキで速さを落としてから曲がる。それが峠の走り方だな」

## 今回の目標

↓ のブレーキと、何も踏まないときの減速を足します。曲がる速さは、遅いときは回る半径で、速いときはタイヤの摩擦で決めます。

## 手順

### 1. 車の値を足す

`game/car.js` の `CAR` を、次のように書き換えます。`BRAKING`・`COASTING`・`MIN_TURN_RADIUS`・`ROAD_GRIP` が増え、`TURN_RATE` はなくなります。

```js
export const CAR = {
  ACCELERATION: 4, // アクセルを踏んだときに増える速さ（メートル毎秒毎秒）。速くなるほど減る
  BRAKING: 9, // ブレーキで減る速さ
  MAX_SPEED: 47.5, // いちばん速い速さ（メートル毎秒。時速 171 km）
  COASTING: 0.6, // 何も踏まないときに減る速さ
  MIN_TURN_RADIUS: 6, // いっぱいに切ったときの、いちばん小さい回る半径（メートル）
  ROAD_GRIP: 9, // 道で、横へ滑らずに曲がれる力の上限（メートル毎秒毎秒）
  LENGTH: 4.1, // 車の長さ（メートル）
  WIDTH: 1.7,
};
```

### 2. ブレーキと減速

`updateCar` の上のコメントと、速さの計算を書き換えます。コメントの `input` に `down` が増え、アクセルの行の下に 3 行足します。

```js
// 時間 seconds だけ車を進める。input は { up, down, left, right }
export function updateCar(car, input, seconds) {
  // 速さ: アクセルは速くなるほど効きにくい（いちばん速い速さに近づくと 0 になる）
  if (input.up) car.speed += CAR.ACCELERATION * (1 - car.speed / CAR.MAX_SPEED) * seconds;
  if (input.down) car.speed -= CAR.BRAKING * seconds;
  if (!input.up && !input.down) car.speed -= CAR.COASTING * seconds;
  car.speed = Math.max(car.speed, 0);
```

最後の `Math.max(car.speed, 0)` を忘れると、ブレーキを踏み続けたときに速さがマイナスになります。すると、車が後ろへ進みます。

### 3. 曲がる速さ

その下の、向きの計算を書き換えます。`turnRate` の行が増え、`CAR.TURN_RATE` の代わりに使います。

```js
  // 向き: 遅いときは回る半径で、速いときはタイヤの摩擦（グリップ）で、曲がれる速さが決まる
  const steer = (input.right ? 1 : 0) - (input.left ? 1 : 0);
  const turnRate = Math.min(car.speed / CAR.MIN_TURN_RADIUS, CAR.ROAD_GRIP / Math.max(car.speed, 0.1));
  car.heading += steer * turnRate * seconds;
```

位置の計算（`Math.sin` と `Math.cos` の 2 行）と `return car;` は、そのままです。

### 4. 走らせる

保存して動かし、プレビューをクリックしてから試します。

- 止まったまま ← を押しても、車は回らない
- ↑ で走りながら ← か → を押すと、遅いときは小さく、速いときは大きく回る
- ↓ を押すと遅くなり、止まったら止まったままになる
- 何も押さないと、少しずつ遅くなる

こう動けば正しいです。

## しくみ

### ブレーキと、何も踏まないとき

`BRAKING` の 9 は、ブレーキで 1 秒に減る速さ（m/s）です。3-7 の速度計と同じ値です。時速 100 km（約 27.8 m/s）からなら、約 3.1 秒、約 43 m で止まります。

`COASTING` の 0.6 は、何も踏まないときに 1 秒に減る速さです。本物の車は、空気の抵抗やタイヤが転がるときの抵抗で、少しずつ遅くなります。ここでは、それを 1 つの値にまとめています。

`!input.up && !input.down` は、「↑ を押していない、かつ ↓ も押していない」です。どちらも押していないときだけ、この減速が入ります。

### ゲンさんの知恵 その 1: 遅いときは、回る半径

> ハンドルをいっぱいに切っても、車は半径 6 m より小さい円は回れない。

半径 r の円を速さ v で 1 周すると、走る道のりは 2πr です。その間に、車の向きもちょうど 1 周（2π）回ります。だから、1 秒に回る角度は v ÷ r です。`car.speed / CAR.MIN_TURN_RADIUS` がこの式です。止まっていれば v が 0 なので、向きは変わりません。

### ゲンさんの知恵 その 2: 速いときは、タイヤの摩擦

> 曲がるときは、車を円の中心へ向ける力が要る。その力は、タイヤと道の摩擦から出る。乾いた道なら、加速度にして 9 m/s² くらいが上限だな。

円を回るときに要る、中心へ向かう加速度は、v × 1 秒に回る角度です。これがタイヤの摩擦の上限 9 m/s²（`ROAD_GRIP`）を越えると、タイヤが横へ滑ります。越えないためには、1 秒に回る角度を 9 ÷ v 以下にします。速いほど、回れる角度は小さくなります。

### 2 つの上限の、小さい方

`Math.min` は、2 つの上限の小さい方を返します。2 つが等しくなるのは v ÷ 6 = 9 ÷ v のときで、v は約 7.3 m/s（時速約 26 km）です。それより遅いと回る半径で、速いとタイヤの摩擦で決まります。

| 速さ | 1 秒に回れる角度 | 回る円の半径 |
|---|---|---|
| 時速 10 km | 約 27 度 | 6 m |
| 時速 30 km | 約 62 度 | 約 8 m |
| 時速 60 km | 約 31 度 | 約 31 m |
| 時速 100 km | 約 19 度 | 約 86 m |
| 時速 171 km | 約 11 度 | 約 251 m |

速いときの半径は、v × v ÷ 9 で求まります。時速 100 km で曲がるには、半径 86 m の大きなカーブが要ります。峠の急なカーブの前でブレーキを踏むのは、このためです。

`Math.max(car.speed, 0.1)` は、止まっているときに 0 で割らないための書き方です。

## 答え合わせ

- ブレーキ（↓）で遅くなり、0 で止まる（後ろへは進まない）
- 何も踏まないと、少しずつ遅くなる
- 止まっているときは、ハンドルを切っても回らない
- 速いときほど、1 秒に回れる角度が小さい（タイヤの摩擦の上限）

通らないときは、手順 2 で足した 3 行と、手順 3 の `turnRate` の行を見直します。「手本との違い」ボタンでも比べられます。

## 変えてみよう

### 1. 雨の日の道

雨の道は滑りやすく、タイヤの摩擦の上限が下がります。`ROAD_GRIP` を 5 にして走り、曲がり方を比べます。

:::answer
速いときの回る半径が大きくなります。時速 100 km では、約 86 m から約 154 m に広がります。半径は v × v ÷ 摩擦の上限 で求まるので、上限が小さいほど大回りになります。試したら 9 に戻します。
:::

### 2. 止まるまでの距離

時速 100 km からブレーキで止まるまでの距離は、v × v ÷ (2 × 9) で求まります。`main.js` の終わりに `console.log` を書いて計算します。

:::answer
```js
const v = 100 / 3.6;
console.log('止まるまで', v * v / (2 * 9), 'm');
```

約 42.9 m と出ます。確かめたら消します。
:::

### 3. 小回りの車

`MIN_TURN_RADIUS` を 3 にすると、どの速さのときの曲がり方が変わるでしょう。

:::answer
時速約 26 km より遅いときだけ、前より小さく回れます。それより速いと、回れる角度はタイヤの摩擦の 9 ÷ v で決まるので、変わりません。試したら 6 に戻します。
:::
