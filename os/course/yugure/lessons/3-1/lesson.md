# 3-1 コンソールで計算

## 場面

看板が立った次の日、ゲンさんが古いメモの束を持ってきました。走り方の覚え書きが、細かい字で並んでいます。

> 第 1 コーナーの手前で、秒速 25 メートル。

ミナが首をかしげます。「秒速 25 メートルって、時速だと何キロなの？ 看板は km/h で書いてあるよ」

ゲンさん「昔は秒速で測っていたからな。掛け算を 1 回すれば直せるんだが」

イコちゃん「その掛け算を、JavaScript でしてみましょう。第 3 部では、JavaScript で速度計と時計を動かします」

## 今回の目標

秒速 25 メートルを時速に直した答えと、数えた周回の数を、コンソールに出します。

## 手順

### 1. 練習のページを開く

ファイルの一覧に、meter.html と meter.js が増えています。meter.html は、準備中だったページを置き換えた練習用のページです。

エディタで meter.html を開いて、head の中を見ます。次の 2 行があります。

```html
  <link rel="stylesheet" href="style.css">
  <script type="module" src="meter.js"></script>
```

1 行目は、看板と同じ見た目のファイルをつなぎます。2 行目は、JavaScript のファイル meter.js を読み込みます。0-2 では、`<script>` の中に JavaScript を直接書きました。今回からは、JavaScript を別のファイルに分けて書きます。`type="module"` の意味は、次の課で説明します。

「保存」（Ctrl+S）を押してから「動かす」（Ctrl+Enter）を押します。プレビューに「速度計とラップタイマー」の見出しと、「練習」の箱が出れば正しいです。

プレビューの見出しの横には、動いているファイルの名前が出ます。講座の窓がこの課を開くと、作業場は meter.html を開いて動かします。meter.js を開いて保存したときも、動くのは meter.html です。この課の答えは、meter.html のプレビューの下にあるコンソールに出ます。

次に meter.js を開きます。中身は、まだ 1 行だけです。

```js
// 速度計とラップタイマー（第 3 部で少しずつ作る）
```

`//` から行の終わりまでは、コメント（comment）です。人が読むためのメモで、動きには関係しません。

### 2. 秒速を時速に直す

1 秒に 25 メートル進む車は、1 時間（3,600 秒）で 90,000 メートル進みます。90,000 メートルは 90 キロメートルです。3,600 を掛けて 1,000 で割るので、まとめると 3.6 を掛ければ時速になります。

meter.js のコメントの行の下に 1 行あけて、次のように書きます。

```js
// 速度計とラップタイマー（第 3 部で少しずつ作る）

// ---- 値と変数 ----
const metersPerSecond = 25; // 秒速 25 メートル（変わらない値は const）
const kmh = metersPerSecond * 3.6; // 時速に直す
console.log('秒速', metersPerSecond, 'メートルは、時速', kmh, 'キロメートル');
```

プログラムが扱う数や文字を、値（value）と呼びます。`const metersPerSecond = 25;` は、25 という値に metersPerSecond という名前を付けます。名前を付けて値を覚えておく入れ物を、変数（variable）と呼びます。

2 行目の `*` は、掛け算の記号です。metersPerSecond に 3.6 を掛けた答えを、変数 kmh に入れます。3 行目の `console.log(...)` は、かっこの中の値をコンソールに出します。

保存して動かすと、コンソールに「秒速 25 メートルは、時速 90 キロメートル」と出ます。console.log は、カンマで区切った値の間に空白を 1 つはさんで、1 行に並べます。

`；` や `＊` のように記号を全角で打つと、コンソールに「誤り」が出ます。よくある間違いなので、記号は半角で打ちます。

### 3. 周回の数を数える

console.log の行の下に 1 行あけて、次の 4 行を書きます。

```js
let laps = 0; // 周回の数（変わる値は let）
laps = laps + 1;
laps = laps + 1;
console.log('周回', laps);
```

あとで値を入れ直す変数は、let で作ります。1 行目で、周回の数 laps を 0 から始めます。2 行目と 3 行目は、それぞれ laps に 1 を足します。

保存して動かすと、コンソールの 2 行目に「周回 2」が出ます。

## しくみ

### 値の種類

25 や 3.6 は、数（number）の値です。`'秒速'` のように `'` で囲んだ文字の並びは、文字列（string）の値です。文字列は、`'` で囲み忘れると「誤り」になります。

### const と let

変数を作る書き方は 2 つあります。

| 書き方 | 意味 | この課で使った所 |
|---|---|---|
| `const` | あとで値を入れ直さない | 秒速、時速 |
| `let` | あとで値を入れ直す | 周回の数 |

迷ったら const で作り、入れ直す必要が出たら let にします。変数の名前は、英語で付けます。metersPerSecond のように、2 つ目からの単語の頭を大文字にする書き方がよく使われます。

### 計算の記号

| 記号 | 計算 | 例 | 答え |
|---|---|---|---|
| `+` | 足し算 | `2 + 3` | 5 |
| `-` | 引き算 | `10 - 4` | 6 |
| `*` | 掛け算 | `25 * 3.6` | 90 |
| `/` | 割り算 | `90 / 3.6` | 25 |

### = は「入れる」記号

`laps = laps + 1;` の `=` は、数学の「等しい」ではありません。右側を先に計算して、その答えを左側の変数に入れる記号です。これを代入（assignment）と呼びます。

laps が 0 のとき、右側の `laps + 1` は 1 です。その 1 が laps に入ります。もう一度同じ行を動かすと、laps は 2 になります。

### 文とコンソール

1 つの命令を、文（statement）と呼びます。文の終わりには `;` を付けます。`console.log` は、コンソール（console）に値を出す命令です。計算の答えを確かめたいときや、プログラムの動きを調べたいときに使います。

## 答え合わせ

- 秒速 25 メートルを時速に直した答え（90）がコンソールに出ている
- 周回の数を 2 回増やして、2 が出ている

通らないときは、プレビューの見出しの横が meter.html か、コンソールに「誤り」が出ていないかを見ます。「手本との違い」を押すと、自分の meter.js と手本の違う行が分かります。

## 変えてみよう

### 1. 時速を秒速に戻す

時速 54 キロメートルは、秒速何メートルでしょう。3.6 で割ると求められます。

:::answer
```js
console.log(54 / 3.6);
```

コンソールに 15 が出ます。秒速 15 メートルです。
:::

### 2. 峠を 1 周する時間

夕暮れ峠は、1 周 1,981 メートルです。秒速 25 メートルのまま走ると、1 周に何秒かかるでしょう。

:::answer
```js
console.log(1981 / 25, '秒');
```

「79.24 秒」と出ます。プログラムの中の数には、`1,981` のようなカンマを入れません。`console.log(1,981 / 25)` と書くと、1 と `981 / 25` を別々の値として出します。
:::

### 3. let を const にすると

`let laps = 0;` を `const laps = 0;` に変えて保存すると、どうなるでしょう。

:::answer
コンソールに `Assignment to constant variable.` を含む「誤り」が出ます。const で作った変数には、あとから値を入れ直せないからです。確かめたら let に戻します。
:::
