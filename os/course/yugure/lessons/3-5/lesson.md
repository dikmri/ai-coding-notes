# 3-5 まとめて持つ

## 場面

ミナが、紙に変数の名前を書き出しました。「carName と carSpeed、minaCarName と minaCarSpeed。車が 1 台増えるたびに、変数が 2 つずつ増えるよ」

ゲンさん「整備の伝票は、車 1 台に 1 枚だ。名前も走った距離も、その 1 枚に書く。プログラムでも、そうできないのかい」

イコちゃん「できます。名前と速さに見出しを付けて、1 つにまとめる書き方があります」

## 今回の目標

いくつかの値に名前を付けて、ひとまとめにしたものを、オブジェクト（object）と呼びます。車の名前と速さを 1 つのオブジェクトにまとめ、答え合わせのための窓口も作ります。

## 手順

### 1. 車のオブジェクトを作る

meter.js の最後の行は、bestLap を呼ぶ console.log です。その下に 1 行あけて、次のように書きます。

```js
// ---- まとめて持つ: 車の名前と速さを、1 つのオブジェクトにまとめる ----
const car = {
  name: 'ゲンさんのハッチバック',
  speed: 0, // メートル毎秒
};
```

`{` と `}` の中に、「名前: 値」の組をカンマで区切って並べます。name や speed のような値の名前を、プロパティ（property）と呼びます。speed の単位はメートル毎秒、つまり秒速です。

保存して動かします。作っただけなので、コンソールは前の課と同じ 5 行のままです。

### 2. 速さを変えて、時速で出す

オブジェクトの `};` の下に、次の 2 行を書きます。

```js
car.speed = 30;
console.log(car.name, 'は、時速', toKmh(car.speed), 'キロメートル');
```

`car.speed` のように、オブジェクトの名前とプロパティの名前を `.` でつなぐと、その値を読めます。`=` で値を入れれば、プロパティの値を変えられます。

保存して動かすと、コンソールの 6 行目に「ゲンさんのハッチバック は、時速 108 キロメートル」と出ます。秒速 30 メートルは、時速 108 キロメートルです。

### 3. 答え合わせの窓口を作る

ファイルの最後に 1 行あけて、次の 2 行を書きます。

```js
// 答え合わせのために、状態を外から読めるようにしておく
window.course = { car };
```

この行は、答え合わせが車のオブジェクトを読むための窓口です。答え合わせは window.course から car を取り出して、名前が文字列か、速さが数かを確かめます。保存して動かしても、見た目とコンソールは変わりません。

## しくみ

### プロパティを読む・書く

| 書き方 | すること | 結果 |
|---|---|---|
| `car.name` | name を読む | 'ゲンさんのハッチバック' |
| `car.speed = 30` | speed に 30 を入れる | speed が 30 になる |
| `toKmh(car.speed)` | speed の値を関数に渡す | 108 |

### 配列とオブジェクトの使い分け

配列は、値を順番で並べて持ちます。周回の記録のように、同じ種類の値がいくつも続くときに使います。

オブジェクトは、値を名前で持ちます。1 台の車の名前と速さのように、種類の違う値をまとめるときに使います。車が 2 台になったら、オブジェクトを 2 つ作ります。

### const でも中身は変えられる

car は const で作りましたが、`car.speed = 30` で速さを変えられました。const が止めるのは、car という変数に別の値を入れ直すことです。car に入っているオブジェクトのプロパティは、あとから変えられます。

### window と答え合わせの窓口

window は、ブラウザのページ全体を表すオブジェクトです。window にプロパティを足すと、ページの中のどこからでも読めます。この講座では、答え合わせで見たい値を window.course に入れておきます。

`{ car }` は、`{ car: car }` を短く書いたものです。プロパティの名前と変数の名前が同じときに、この書き方を使えます。window.course.car は、手順 1 で作った車のオブジェクトそのものです。

### 最後のカンマ

`speed: 0,` のように、最後のプロパティのあとにもカンマを付けておけます。付けておくと、あとからプロパティを足すときに、カンマを書き忘れずに済みます。

## 答え合わせ

- 車のオブジェクトに、名前（文字）と速さ（数）がある
- 車の名前と時速（108）がコンソールに出ている

通らないときは、name の値を `'` で囲んだかを見ます。speed を `'0'` のように `'` で囲むと、数ではなく文字列になるので通りません。

## 変えてみよう

### 1. ミナの車

ミナの車のオブジェクト minaCar を作り、名前と時速をコンソールに出します。速さは秒速 20 メートルにします。

:::answer
```js
const minaCar = {
  name: 'ミナの青い車',
  speed: 20, // メートル毎秒
};
console.log(minaCar.name, 'は、時速', toKmh(minaCar.speed), 'キロメートル');
```

「ミナの青い車 は、時速 72 キロメートル」と出ます。車が増えても、オブジェクトを 1 つ足すだけで済みます。
:::

### 2. プロパティを足す

car に、変速の段の数を表すプロパティ gears を足します。値は 5 です。足したら、段の数をコンソールに出します。

:::answer
car のオブジェクトを、次のようにします。

```js
const car = {
  name: 'ゲンさんのハッチバック',
  speed: 0, // メートル毎秒
  gears: 5,
};
```

`car.speed = 30;` の行より下に、次の行を書きます。

```js
console.log(car.name, 'は', car.gears, '段の変速');
```
:::

### 3. いまの段も出す

3-3 で作った gearFor を使って、car のいまの速さが何速かを出します。

:::answer
```js
console.log(car.name, 'は', gearFor(toKmh(car.speed)), '速');
```

`car.speed = 30;` の行より下に書くと、「ゲンさんのハッチバック は 4 速」と出ます。時速 108 キロメートルは、75 以上で 110 より下なので 4 速です。
:::
