# 2-3 横に並べる

## 場面
ミナが「ここが楽しい」の箱を指さしました。

ミナ「点の付いた 3 行だと、読み飛ばしちゃうよ。お菓子の箱みたいに、カードが横に並んでたらいいな」
ゲンさん「工場の棚も、よく使う工具は横一列に並べてあるな」
イコちゃん「横に並べるには flex を使います。画面が狭いときに、次の行へ折り返すようにもできますよ」

## 今回の目標
特徴の箇条書き（.cards）を flex にして、3 枚のカードを横に並べます。並びきらないときは、次の行へ折り返すようにします。

## 手順
### 1. 並べる箱を flex にする
style.css の最後（img の規則の下）に足します。

```css
/* 特徴のカードを横に並べる（flex）。狭い画面では折り返す */
.cards {
  display: flex;
  flex-wrap: wrap;
  gap: 12px;
  padding: 0;
  list-style: none;
}
```

保存して動かします。箇条書きの点と、左の字下げが消えます。3 つの項目が横に並び、幅が足りない項目は次の行へ移ります。

### 2. 項目をカードの形にする
続けて、カード 1 枚ずつの規則を足します。

```css
.cards li {
  flex: 1 1 200px;
  padding: 12px;
  border: 1px solid #e3d6c3;
  border-radius: 8px;
}
```

保存して動かします。3 つの項目が、角の丸い枠のカードになります。プレビューが広いときは、3 枚が同じ幅で横 1 行に並び、箱の幅いっぱいまで広がります。

`.cards` と `li` の間の空白を忘れて `.cardsli` と書くと、cardsli という名札を探すことになります。カードの形にならないときは、空白を確かめてください。

### 3. 幅を変えて確かめる
窓の幅を変えて、プレビューを狭くしてみましょう。

カードの基本の幅は 200px です。3 枚を横に並べるには 624px が要ります。200px の 3 枚分と、すき間 12px の 2 つ分です。並びの幅がそれより狭くなると、3 枚目が次の行へ移ります。さらに狭くすると、カードは 1 枚ずつ上から下へ並びます。

## しくみ
### flex の箱と中身
`display: flex` を決めた要素を、フレックスコンテナー（flex container）と呼びます。そのすぐ中にある要素はフレックスアイテム（flex item）になり、横に並びます。今回は ul がコンテナー、3 つの li がアイテムです。

flex は、1 つの向きを決めて要素を並べるしくみです。向きは最初は横で、`flex-direction: column` にすると縦になります。

### 折り返しとすき間
- `flex-wrap: wrap` は、並びきらないアイテムを次の行へ送ります。書かないと、アイテムは 1 行のまま縮みます
- `gap: 12px` は、アイテムとアイテムの間だけにすき間を空けます。並びの両端には空きません

### カードの幅を決める flex
`flex: 1 1 200px` は、3 つの値をまとめて書いた形です。

| 値 | 名前 | 意味 |
|---|---|---|
| 1 | flex-grow | 行に余った幅を、ほかのカードと同じ割合で分けてもらう |
| 1 | flex-shrink | 幅が足りないときは、同じ割合で縮む |
| 200px | flex-basis | 余りを分ける前の、基本の幅 |

ブラウザは、まず 1 行に、基本の幅のカードを入るだけ入れます。そのあと、行に余った幅を flex-grow の割合で分けます。そのため、どの行もカードで端まで埋まります。

### 箇条書きの点と字下げ
ul は最初から、項目の頭に点を付け、左に 40px の padding を持っています。`list-style: none` が点を消し、`padding: 0` が字下げを消します。

### 中にある要素を選ぶ
`.cards li` のように空白でつなぐと、「名札が cards の要素の中にある li」を選びます。これを子孫セレクタ（descendant selector）と呼びます。ページのほかの場所に li があっても、この規則は当たりません。

## 答え合わせ
- カードの並び（.cards）が flex になっている
- 広い画面で、最初の 2 枚のカードが横に並んでいる
- カードの間にすき間（gap）がある
- 箇条書きの点（list-style）を消した

通らないときは、`.cards` の規則の `display` と `gap` のつづりを見直してください。2 つ目の確かめは、広い画面のときの並び方を見ます。「手本との違い」で手本と見比べることもできます。

## 変えてみよう
### 1. カードの基本の幅を広げる
`flex` の 3 つ目の値を `400px` にして、広い画面でカードが何枚ずつ並ぶか確かめましょう。

:::answer
```css
.cards li {
  flex: 1 1 400px;
  padding: 12px;
  border: 1px solid #e3d6c3;
  border-radius: 8px;
}
```

3 枚には 1,224px が要るので、広い画面でも入りません。カードは 2 枚と 1 枚に分かれ、下の 1 枚は行の幅いっぱいに広がります。並びの幅が 812px より狭いと、1 枚ずつになります。試したら 200px に戻しておきましょう。
:::

### 2. 縦に並べる
`.cards` に `flex-direction: column` を足すと、どう並ぶか確かめましょう。

:::answer
```css
.cards {
  display: flex;
  flex-direction: column;
  flex-wrap: wrap;
  gap: 12px;
  padding: 0;
  list-style: none;
}
```

カードが縦に並び、12px のすき間は上下の間に空きます。並ぶ向きが縦になると、flex-basis の 200px は高さとして使われます。そのため、カードが縦に長くなります。確かめの「横に並んでいる」は通らなくなるので、試したら行を消しておきましょう。
:::

### 3. 折り返さないとどうなるか
`flex-wrap: wrap;` の行を消して、プレビューを狭くしてみましょう。

:::answer
折り返さないので、3 枚は狭い幅でも 1 行に並んだまま縮みます。カードの中の文字が細かく折り返され、縦に長いカードになります。確かめたら、`flex-wrap: wrap;` の行を元に戻しましょう。
:::
