# 0-1 古いフォルダ

## 場面

Future OS のファイルを見ていたあなたは、見覚えのないフォルダに気づきます。フォルダの名前は「夕暮れ峠」です。

イコちゃん「ずいぶん前からあるフォルダですね。中には index.html というファイルが 1 つ入っています」

ファイルの名前は分かっても、中に何が書いてあるのかは分かりません。

イコちゃん「作業場で開くと、中身を読んだり、動かして確かめたりできます。一緒に見てみましょう」

## 今回の目標

作業場の各部分の場所と役目を知り、フォルダの中のメモを動かして読みます。この課では、コードを打ちません。

## 手順

### 1. 作業場の部分を知る

講座の窓の右側に、作業場が開いています。作業場には、プロジェクトのフォルダ `/プロジェクト/夕暮れ峠` が読み込まれています。

作業場は、次の部分でできています。

| 部分 | 場所 | 役目 |
|---|---|---|
| ファイルの一覧 | 左 | フォルダの中のファイルを並べる |
| エディタ | 真ん中 | 選んだファイルの中身を表示し、書き換える |
| 「保存」「動かす」 | 上の列 | 書き換えた中身を保存する（Ctrl+S）。ページを動かす（Ctrl+Enter） |
| プレビュー | 右 | 動かしたページを表示する |
| コンソール | プレビューの下 | ページが出した文字を表示する。「消す」で表示を空にする |

### 2. メモを読む

ファイルの一覧で `index.html` を選びます。エディタに、次の中身が表示されます。今回は読むだけで、書き換えません。

```html
<!DOCTYPE html>
<html lang="ja">
<head>
  <meta charset="utf-8">
  <title>夕暮れ峠</title>
</head>
<body>
  <h1>夕暮れ峠</h1>
  <p>この峠を、もう一度走らせてほしい。 ― とんぼ整備工場 ゲン</p>
  <p>このフォルダを開いた人の名前: ？？？</p>
  <script>
    console.log('夕暮れ峠のフォルダが開かれました');
  </script>
</body>
</html>
```

`<` と `>` で囲まれた英字は、ページの組み立てを表す印です。印の間にある日本語が、メモの文です。`console.log` で始まる行は、コンソールに文字を出す行です。

### 3. 動かす

「動かす」を押します。Ctrl+Enter でも同じです。プレビューに大きな文字で「夕暮れ峠」と出て、その下に 2 行の文が出れば正しく動いています。

メモの書き手は、とんぼ整備工場のゲンさんという人のようです。

### 4. コンソールを見る

プレビューの下のコンソールに、「夕暮れ峠のフォルダが開かれました」と出ています。この文はプレビューの画面には出ず、コンソールにだけ出ます。

コンソールの「消す」を押すと、表示が空になります。もう一度「動かす」を押すと、同じ文がまた出ます。ページを動かすたびに、`console.log` の行が文字を出すからです。

### 5. 講座の窓のボタンを知る

講座の窓には、次のボタンがあります。この先の課でも使います。

| ボタン | 使うとき |
|---|---|
| 答え合わせ | この課でやることができたかを確かめる |
| この課の始めに戻す | ファイルを、この課の始めの中身に戻す |
| 手本との違い | 自分のファイルと手本の、違う行を見る |
| 代わりにやって | 手本のとおりに、代わりに書き換えてもらう |
| 次の課へ | 次の課に進む |

## しくみ

### ファイルの住所

`index.html` は、`/プロジェクト/夕暮れ峠` というフォルダの中にあります。ファイルの場所は、フォルダの名前を `/` でつないで `/プロジェクト/夕暮れ峠/index.html` のように書きます。この書き方をパス（path）と呼びます。この講座では「ファイルの住所」とも呼びます。

### HTML とブラウザ

`index.html` の中身は、HTML（エイチ・ティー・エム・エル）という言葉で書いてあります。HTML は、Web のページの中身と組み立てを書くための言葉です。

ブラウザ（browser）は HTML を読み、見出しや文を画面に表示します。作業場のプレビューは、作業場の中にある小さなブラウザです。

### コンソール

コンソール（console）は、ページを作る人が見るための表示です。ページを見る人の画面には出ない文字を出して、ページの中で何が起きたかを確かめるときに使います。

## 答え合わせ

「答え合わせ」を押すと、次の項目を確かめます。

- index.html があり、見出しに「夕暮れ峠」と書いてある
- プレビューのコンソールに、フォルダが開かれたことが出ている

通らないときは、「動かす」を押してから、もう一度「答え合わせ」を押します。エディタの文字をうっかり消したときは、「この課の始めに戻す」で元に戻せます。

## 変えてみよう

### 1. コンソールの文を出している行を探す

エディタの左には、行の番号が出ています。コンソールに「夕暮れ峠のフォルダが開かれました」と出しているのは、何行目でしょうか。

:::answer
12 行目の `console.log('夕暮れ峠のフォルダが開かれました');` です。11 行目の `<script>` と、13 行目の `</script>` の間にあります。
:::

### 2. プレビューに出ない日本語を探す

エディタにはあるのに、プレビューの画面には出ていない日本語が 2 か所あります。どこでしょうか。

:::answer
5 行目の `<title>` と `</title>` の間の「夕暮れ峠」と、12 行目のコンソールの文です。`<title>` の文字はページの題名で、ブラウザではタブなどに出ます。ページの中には出ません。コンソールの文は、コンソールにだけ出ます。
:::
