# 3-2 秒速を時速に

## 場面

ゲンさんのメモには、秒速の数がいくつも並んでいます。最後のページには、こう書いてありました。

> わしの車がいちばん速く走ったとき、秒速 47.5 メートル。

ミナ「これも 3.6 を掛けるんだよね。毎回 `* 3.6` と書いていたら、いつか 36 と打ち間違えそうだよ」

イコちゃん「掛け算に名前を付けておけば、名前を書くだけで同じ計算ができます。今日はその作り方を覚えましょう」

## 今回の目標

決まった計算に名前を付けたものを、関数（function）と呼びます。秒速を時速に直す関数 toKmh を作り、ゲンさんの車のいちばん速い速さを時速で出します。

## 手順

### 1. 関数を作る

meter.js の最後の行（`console.log('周回', laps);`）の下に 1 行あけて、次のように書きます。

```js
// ---- 関数: 秒速（メートル毎秒）を、時速（キロメートル毎時）に直す ----
export function toKmh(metersPerSecond) {
  return metersPerSecond * 3.6;
}
```

`function toKmh(...)` で、toKmh という名前の関数を作ります。関数に渡す値を、引数（argument）と呼びます。かっこの中の metersPerSecond は、渡された引数を受け取る変数です。

`{` と `}` の間が、関数の中身です。`return` は、計算の答えを関数の外へ返します。先頭の `export` は、ほかのファイルや答え合わせから toKmh を使えるようにするために付けます。

保存して動かします。関数は作っただけでは動かないので、コンソールは前の課と同じ 2 行のままです。「誤り」が出ていなければ正しいです。

`{` を書いて、対になる `}` を書き忘れると、「誤り」が出ます。`{` を書いたら、すぐに `}` も書いておくと間違えにくくなります。

### 2. 関数を呼ぶ

関数の `}` の下に、次の 1 行を書きます。

```js
console.log('ゲンさんの車のいちばん速い速さは、時速', toKmh(47.5), 'キロメートル');
```

`toKmh(47.5)` のように、関数の名前のあとのかっこに値を書くと、関数の中身が動きます。これを、関数を呼ぶ（call）と言います。47.5 が metersPerSecond に入り、`47.5 * 3.6` の答えの 171 が返ります。

保存して動かすと、コンソールの 3 行目に「ゲンさんの車のいちばん速い速さは、時速 171 キロメートル」と出ます。看板の札の「最高 171 km/h」と同じ数です。

## しくみ

### 関数の形

```js
function 名前(引数) {
  return 返す値;
}
```

関数を作ることを、関数を定義する（define）と言います。定義しただけでは、中身は動きません。呼んだときに、初めて動きます。何度呼んでもかまいません。

### 呼んだ所が、返した値になる

| 書いたもの | 中でする計算 | 返る値 |
|---|---|---|
| `toKmh(10)` | `10 * 3.6` | 36 |
| `toKmh(25)` | `25 * 3.6` | 90 |
| `toKmh(47.5)` | `47.5 * 3.6` | 171 |

手順 2 の console.log は、toKmh が返した 171 を受け取って、コンソールに出します。計算の式を書き直さなくても、名前と引数を書くだけで同じ計算ができます。

### 同じ名前でも、別の変数

3-1 で作った `const metersPerSecond = 25;` と、toKmh の引数の metersPerSecond は、名前が同じでも別の変数です。引数は、関数の中だけで使える変数です。

関数の中で metersPerSecond と書くと、引数のほうを使います。だから toKmh(47.5) は、25 ではなく 47.5 で計算します。

### export と type="module"

`export` を付けた関数は、ほかのファイルや答え合わせから読み込んで使えます。この課の答え合わせは、meter.js から toKmh を読み込みます。そして、toKmh(10) が 36 を返すかを確かめます。

export を書けるのは、`type="module"` で読み込んだファイルだけです。meter.html の `<script type="module" src="meter.js">` は、そのための書き方です。ファイルどうしで読み込み合うモジュール（module）のしくみは、第 4 部で詳しく扱います。

## 答え合わせ

- 関数 toKmh を作り、外から使えるように export した
- toKmh(10) が 36 を返す
- ゲンさんの車の速さ（171）がコンソールに出ている

通らないときは、`export function toKmh` のつづりと、`return` の書き忘れを確かめます。「手本との違い」を押すと、手本と違う行が分かります。

## 変えてみよう

### 1. 時速を秒速に直す関数

toKmh とは逆に、時速を秒速に直す関数 toMps を作ります。toMps(171) が 47.5 を返せば正しいです。

:::answer
```js
export function toMps(kmh) {
  return kmh / 3.6;
}
console.log(toMps(171));
```

関数の中の kmh は引数です。3-1 で作った const kmh とは別の変数です。
:::

### 2. 引数を 2 つにする

引数は、カンマで区切れば 2 つ以上にできます。道のりと秒速を受け取り、かかる秒数を返す関数 lapSeconds を作ります。夕暮れ峠の 1,981 メートルを秒速 25 メートルで走ると、79.24 秒です。

:::answer
```js
export function lapSeconds(distance, speed) {
  return distance / speed;
}
console.log(lapSeconds(1981, 25), '秒');
```

1 つ目の 1981 が distance に、2 つ目の 25 が speed に入ります。
:::

### 3. return を消すと

toKmh の `return` を消して、`metersPerSecond * 3.6;` だけにします。コンソールには何が出るでしょう。

:::answer
「時速 undefined キロメートル」と出ます。undefined は、値がないことを表す値です。return がない関数は、計算はしても答えを返しません。確かめたら return を元に戻します。
:::
