# 3-3 もし〜なら

## 場面

ゲンさんが、変速の段の上げ方を書いたメモを見せてくれました。

> 時速 20 キロになったら 2 速に上げる。
> 45 キロで 3 速、75 キロで 4 速。
> 110 キロで 5 速。

ミナ「速さによって、答えが 1 速から 5 速まで変わるんだね。3.6 を掛けるみたいに、式 1 つでは書けないよ」

イコちゃん「『もし〜なら、こうする』という書き方を使いましょう。ゲンさんのメモを、そのまま JavaScript にできます」

## 今回の目標

時速から変速の段を決める関数 gearFor を作ります。「もし〜なら」を書く if を使います。

## 手順

### 1. 段の決め方を表にする

ゲンさんのメモを、表にします。

| 時速（キロメートル） | 段 |
|---|---|
| 20 より下 | 1 速 |
| 20 以上、45 より下 | 2 速 |
| 45 以上、75 より下 | 3 速 |
| 75 以上、110 より下 | 4 速 |
| 110 以上 | 5 速 |

メモには「20 キロになったら 2 速」とあります。だから、ちょうど時速 20 キロメートルのときは 2 速です。境目の数をどちらの段に入れるかを、先に決めておきます。

### 2. 関数 gearFor を書く

meter.js の最後の行は、toKmh を呼ぶ console.log です。その下に 1 行あけて、次のように書きます。

```js
// ---- もし〜なら: 時速から、変速の段を決める（ゲンさんの車は 5 段） ----
export function gearFor(kmh) {
  if (kmh < 20) {
    return 1;
  } else if (kmh < 45) {
    return 2;
  } else if (kmh < 75) {
    return 3;
  } else if (kmh < 110) {
    return 4;
  }
  return 5;
}
```

`if (kmh < 20)` は、「もし kmh が 20 より小さいなら」という意味です。条件に当てはまると、すぐ後の `{ }` の中を動かします。当てはまらないときは、`else if` の次の条件を調べます。どれにも当てはまらないときは、最後の `return 5;` まで進みます。

行の頭の空白を、字下げ（indent）と呼びます。字下げをそろえて書くと、対になる `{` と `}` を見つけやすくなります。`}` を 1 つ書き忘れると、「誤り」が出ます。

### 3. 関数を呼んで確かめる

関数の `}` の下に、次の 1 行を書きます。

```js
console.log('時速 60 キロメートルは', gearFor(60), '速');
```

保存して動かすと、コンソールの 4 行目に「時速 60 キロメートルは 3 速」と出ます。60 は 45 以上で 75 より下なので、3 速です。

## しくみ

### 比べる記号

| 記号 | 意味 | 例 | 結果 |
|---|---|---|---|
| `<` | より小さい | `10 < 20` | true |
| `<=` | 以下 | `20 <= 20` | true |
| `>` | より大きい | `60 > 75` | false |
| `>=` | 以上 | `110 >= 110` | true |
| `===` | 等しい | `20 === 20` | true |
| `!==` | 等しくない | `20 !== 20` | false |

比べた結果は、true（正しい）か false（正しくない）のどちらかです。この 2 つの値を、真偽値（boolean）と呼びます。3-1 で使った `=` は、値を入れる記号でした。等しいかどうかを比べるときは、`===` を使います。

### if と else if と else

```js
if (条件) {
  // 条件が true のとき
} else if (別の条件) {
  // 前の条件が false で、この条件が true のとき
} else {
  // どの条件も false のとき
}
```

このように、条件によって動かす所を分けることを、条件分岐（conditional）と呼びます。gearFor では else の代わりに、最後に `return 5;` を書いています。return を通ると、関数はそこで終わります。だから、どこかで return したあとは、残りの行は動きません。

### 上から順に調べる

条件は、上から順に調べます。gearFor(60) は、次のように進みます。

| 調べる条件 | 60 では | 次にすること |
|---|---|---|
| `kmh < 20` | false | 次の条件へ |
| `kmh < 45` | false | 次の条件へ |
| `kmh < 75` | true | 3 を返して終わる |

2 つ目の条件は `kmh < 45` だけで、「20 以上」とは書いていません。1 つ目の `kmh < 20` が false のときにしか、2 つ目まで進まないからです。条件の順番を入れ替えると、答えが変わります。gearFor では、小さい数の条件から順に並べます。

## 答え合わせ

- 関数 gearFor を作り、export した
- 時速 10 km は 1 速、60 km は 3 速、150 km は 5 速
- 境目（時速 20 km）は 2 速

通らないときは、`<` の向きと、20・45・75・110 の数を確かめます。境目の確かめだけが通らないときは、`<` を `<=` と書いていないかを見ます。

## 変えてみよう

### 1. 関数の答えを、別の関数に渡す

秒速 25 メートルは、何速でしょう。toKmh で時速に直し、その答えを gearFor に渡します。

:::answer
```js
console.log('秒速 25 メートルは', gearFor(toKmh(25)), '速');
```

「秒速 25 メートルは 4 速」と出ます。内側のかっこから計算するので、toKmh(25) が 90 を返し、gearFor(90) が 4 を返します。
:::

### 2. 止まっているときは 0

時速 0 キロメートルのときは、段が入っていないことにして 0 を返します。`===` を使った if を、gearFor の中身の始めに足します。

:::answer
`export function gearFor(kmh) {` の次の行に、次の 3 行を足します。

```js
  if (kmh === 0) {
    return 0;
  }
```

gearFor(0) が 0 を返します。答え合わせの中身は変わらないので、足したままでも通ります。
:::

### 3. else を使う

試しの時速 testSpeed が 171 より大きいときは「出せません」と出します。そうでないときは「走れます」と出します。

:::answer
```js
const testSpeed = 180;
if (testSpeed > 171) {
  console.log('時速', testSpeed, 'キロメートルは、ゲンさんの車では出せません');
} else {
  console.log('時速', testSpeed, 'キロメートルなら走れます');
}
```

testSpeed を 150 に変えると、else の側が動きます。
:::
