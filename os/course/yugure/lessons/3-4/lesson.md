# 3-4 何度も

## 場面

ミナがメモをのぞきこみます。「3 つなら、見比べればすぐ分かるよ。2 周目の 1 分 21 秒 002 がいちばん速いね」

それから、少し考えて言いました。「でも祭りでは、子どもたちが何十周も走るよ。全部を見比べるのは大変だな」

イコちゃん「記録を 1 つの並びにまとめて、前から順に比べる仕組みを作りましょう。記録が 3 つでも 100 個でも、同じ書き方で選べます」

## 今回の目標

値を順番に並べて 1 つにまとめたものを、配列（array）と呼びます。周回の時間を並べた配列から、いちばん短い時間を選ぶ関数 bestLap を作ります。

## 手順

### 1. 時間をミリ秒の数にする

1 秒は 1,000 ミリ秒で、1 分は 60,000 ミリ秒です。「1 分 23 秒 456」は、60,000 と 23,000 と 456 を足して、83,456 ミリ秒です。

| メモの記録 | ミリ秒 |
|---|---|
| 1 分 23 秒 456 | 83456 |
| 1 分 21 秒 002 | 81002 |
| 1 分 22 秒 500 | 82500 |

分と秒とミリ秒を 1 つの数にしておくと、`<` で大きさを比べられます。

### 2. 関数 bestLap を書く

meter.js の最後の行は、gearFor を呼ぶ console.log です。その下に 1 行あけて、次のように書きます。

```js
// ---- 何度も: 周回の時間（ミリ秒）の並びから、いちばん短いものを探す ----
export function bestLap(laps) {
  let best = Infinity;
  for (const time of laps) {
    if (time < best) {
      best = time;
    }
  }
  return best;
}
```

引数 laps には、周回の時間の配列を渡します。`for (const time of laps) { ... }` は、配列 laps の値を前から 1 つずつ取り出して、time に入れます。そして値の数だけ、`{ }` の中を繰り返します。このような書き方を、繰り返し（loop）と呼びます。

変数 best には、それまでに見つけたいちばん短い時間を入れておきます。始めに入れる Infinity は、どんな数よりも大きい値です。

`return best;` は、for の `}` の外に書きます。繰り返しの中に書くと、1 つ目の値を調べたところで関数が終わってしまいます。

### 3. 記録の配列を作って、関数を呼ぶ

関数の `}` の下に、次の 2 行を書きます。

```js
const lapTimes = [83456, 81002, 82500];
console.log('最速の周回は', bestLap(lapTimes), 'ミリ秒');
```

`[` と `]` の中に値をカンマで区切って並べると、配列になります。

保存して動かすと、コンソールの 5 行目に「最速の周回は 81002 ミリ秒」と出ます。メモの「1 分 21 秒 002」です。

## しくみ

### 配列

配列は、値を順番に並べて持つ入れ物です。`[83456, 81002, 82500]` には、3 つの数が並んでいます。並べる値はいくつでもかまいません。数のほかに、文字列も並べられます。

### for...of で 1 つずつ

`for (const 変数 of 配列) { ... }` は、配列の値を前から順に変数へ入れて、中を繰り返します。この書き方を for...of と呼びます。値が 3 つなら 3 回、100 個なら 100 回繰り返します。

bestLap(lapTimes) は、次のように進みます。

| 回 | time | `time < best` | その回が終わったときの best |
|---|---|---|---|
| 始め | なし | なし | Infinity |
| 1 回目 | 83456 | true | 83456 |
| 2 回目 | 81002 | true | 81002 |
| 3 回目 | 82500 | false | 81002 |

繰り返しが終わったとき、best には 81002 が残っています。それを return で返します。

### Infinity から始める理由

best を 0 から始めると、どの time も 0 より小さくありません。best は 0 のまま変わらず、答えも 0 になります。Infinity から始めれば、1 回目の time が必ず best に入ります。そのあとは、それより短い time が来たときだけ best を入れ替えます。

### 引数の laps は別の変数

bestLap の引数 laps は、3-1 で作った let laps（周回の数）とは別の変数です。3-2 で見たとおり、関数の中で laps と書くと引数のほうを使います。

## 答え合わせ

- 関数 bestLap を作り、export した
- [83456, 81002, 82500] から 81002 を選ぶ
- 並びの最後がいちばん短くても選べる

通らないときは、`time < best` の向きと、`return best;` の場所を確かめます。3 つ目だけが通らないときは、return が for の中に入っていないかを見ます。

## 変えてみよう

### 1. 記録を足す

lapTimes の最後に、79800（1 分 19 秒 800）を足します。答えはどう変わるでしょう。

:::answer
```js
const lapTimes = [83456, 81002, 82500, 79800];
```

「最速の周回は 79800 ミリ秒」と出ます。値が 4 つになっても、関数は書き換えずに使えます。
:::

### 2. いちばん遅い周回

いちばん長い時間を返す関数 worstLap を作ります。

:::answer
```js
export function worstLap(laps) {
  let worst = 0;
  for (const time of laps) {
    if (time > worst) {
      worst = time;
    }
  }
  return worst;
}
console.log('いちばん遅い周回は', worstLap(lapTimes), 'ミリ秒');
```

console.log の行は、`const lapTimes = ...` の行より下に書きます。「いちばん遅い周回は 83456 ミリ秒」と出ます。周回の時間は必ず 0 より長いので、worst は 0 から始められます。
:::

### 3. 合計の時間

3 周の時間を足した合計を、for...of で求めます。

:::answer
```js
let total = 0;
for (const time of lapTimes) {
  total = total + time;
}
console.log('3 周の合計は', total, 'ミリ秒');
```

「3 周の合計は 246958 ミリ秒」と出ます。total は値を入れ直すので、let で作ります。
:::
