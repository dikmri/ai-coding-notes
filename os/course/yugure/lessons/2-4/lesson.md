# 2-4 格子に置く

## 場面
ゲンさんが、祭りのテントに置く大きな画面で看板を開きました。

ゲンさん「箱が縦に 4 つ並んでいるだけで、下まで見るのが大変だ。特徴と操作は、隣同士に置けないかい」
ミナ「でも、スマホで見る子もいるよ。小さい画面では、今のままがいいな」
イコちゃん「画面の幅によって、置き方を変えられます。格子（grid）を使ってみましょう」

## 今回の目標
本体（main）を grid にして、広い画面では 2 列に置きます。狭い画面では 1 列のままにします。

## 手順
### 1. main を grid にする
style.css の最後（`.cards li` の規則の下）に足します。

```css
/* 看板の中身を格子に置く（grid）。広い画面では 2 列 */
main {
  display: grid;
  grid-template-columns: 1fr;
  gap: 0 24px;
}
```

保存して動かします。列は 1 つなので、見た目はほとんど変わりません。

main は、2-2 で書いた `header, main, footer` の規則にも入っています。同じ要素に当たる規則が 2 つあっても、両方の宣言が使われます。

### 2. 広い画面だけ 2 列にする
続けて、画面の幅の条件（@media）を足します。

```css
@media (width >= 760px) {
  main {
    grid-template-columns: 3fr 2fr;
  }
}
```

保存して動かします。プレビューの幅が 760px 以上なら、まとまりが 2 列に並びます。左の列が広く、右の列が狭くなります。プレビューが 760px より狭いときは 1 列のままなので、窓を広げて確かめてください。

このままだと、絵が左の列に、特徴が右の列に入ります。まとまりは HTML の順に、左から右へ、上から下へ置かれるからです。次の手順で直します。

### 3. 絵と「走ってみよう」を 2 列にまたがせる
@media の `{` と `}` の中に、`.hero` と `.start` の規則を足します。

```css
@media (width >= 760px) {
  main {
    grid-template-columns: 3fr 2fr;
  }

  .hero,
  .start {
    grid-column: 1 / -1;
  }
}
```

保存して動かします。広い画面では、いちばん上に絵が幅いっぱいに出ます。その下の左に「ここが楽しい」、右に「操作」が並びます。いちばん下に「走ってみよう」が幅いっぱいに出れば、正しくできています。

特徴の列は前より狭いので、カードは 2 枚と 1 枚に分かれることがあります。2-3 で決めた折り返しのとおりです。

@media の最後の `}` を忘れると、あとで足す規則までが幅の条件の中に入ってしまいます。`{` と `}` の数がそろっているか確かめましょう。

### 4. 幅を変えて確かめる
窓の幅を変えて、プレビューを広げたり狭めたりしてみましょう。760px をまたぐたびに、1 列と 2 列が入れ替わります。

プレビューの中のページにとっては、プレビューの枠の幅が画面の幅です。パソコンの画面が広くても、プレビューが狭ければ 1 列で表示されます。

## しくみ
### grid の格子
`display: grid` を決めた要素は、グリッドコンテナー（grid container）になります。すぐ中の要素は、縦と横の線で区切った格子のます目に置かれます。flex は 1 つの向きに並べるしくみで、grid は縦と横の 2 つの向きをまとめて決めるしくみです。

### 列の幅を決める
`grid-template-columns` には、列の幅を左から順に並べて書きます。書いた数が列の数になります。`fr`（fraction）は、残った幅を分ける割合です。

- `1fr` は、列が 1 つで、幅をすべて使います
- `3fr 2fr` は幅を 5 つに分けて、左の列に 3 つ分、右の列に 2 つ分を渡します

`gap: 0 24px` は、行の間を 0、列の間を 24px にします。行の間は、section の `margin-bottom` ですでに空いているからです。

### 線の番号でまたがせる
格子の縦の線には、左から 1・2・3 と番号が付きます。2 列なら線は 3 本です。`grid-column` には、要素を置く始めの線と終わりの線を、`/` で区切って書きます。`-1` は、右から数えて 1 本目の線を指します。

| 書き方 | 置く場所 |
|---|---|
| `grid-column: 1 / 2` | 左の列だけ |
| `grid-column: 2 / 3` | 右の列だけ |
| `grid-column: 1 / -1` | すべての列にまたがる |

### 幅の条件 @media
`@media` は、条件に合うときだけ中の規則を使う書き方です。これをメディアクエリ（media query）と呼びます。`(width >= 760px)` は、「画面の幅が 760px 以上」という条件です。同じ意味で `(min-width: 760px)` と書いてあるページも多くあります。

今回は、狭い画面の置き方を @media の外に書きました。広い画面で変える所だけを、@media の中に書いています。

## 答え合わせ
- 本体（main）が grid になっている
- 広い画面で 2 列になっている
- 特徴と操作のまとまりが、横に並んでいる
- 絵のまとまり（.hero）は 2 列にまたがっている

通らないときは、@media の `{` と `}` の数と、`grid-template-columns` のつづりを見直してください。2〜4 つ目は、幅が 760px 以上のときの置き方を確かめます。「手本との違い」で手本と見比べることもできます。

## 変えてみよう
### 1. 2 つの列を同じ幅にする
広い画面のとき、左右の列を同じ幅にしてみましょう。

:::answer
```css
@media (width >= 760px) {
  main {
    grid-template-columns: 1fr 1fr;
  }

  .hero,
  .start {
    grid-column: 1 / -1;
  }
}
```

`1fr 1fr` は、幅を 2 つに分けて 1 つずつ渡します。
:::

### 2. 2 列になる境目を変える
境目を 900px にして、どの幅で切り替わるか確かめましょう。

:::answer
`@media` の行の数を変えます。

```css
@media (width >= 900px) {
```

プレビューの幅が 900px 以上のときだけ 2 列になります。試したら 760px に戻しておきましょう。
:::

### 3. 「走ってみよう」を左の列に置く
`.start` を、またがせる規則から外してみましょう。

:::answer
```css
  .hero {
    grid-column: 1 / -1;
  }
```

「走ってみよう」は、特徴の下の左の列に入ります。右の列のその段は空いたままになります。
:::
