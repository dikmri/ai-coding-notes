# 1-3 写真を貼る

## 場面

プロジェクトのフォルダに、img というフォルダが増えました。中には、ゲンさんが描いた峠の絵 `toge.svg` が入っています。

ゲンさん「サーキットがあったころの峠を思い出して描いたんだ。夕方の景色が、いちばんきれいだったな」

今の看板は文字だけなので、峠がどんな景色なのかが伝わりません。

イコちゃん「写真の代わりに、この絵を看板に貼りましょう。絵が見えない人にも伝わるように、絵の中身を文でも書いておきます」

## 今回の目標

峠の絵を看板に貼ります。絵の中身を伝える文と、絵の下に出す説明も付けます。

## 手順

### 1. 絵のファイルを確かめる

ファイルの一覧に、`img/toge.svg` が増えています。選ぶと、エディタに絵の中身が文字で表示されます。SVG（エス・ブイ・ジー）は、線や色を文字で書いて表す絵の形式です。

この課では、toge.svg は書き換えません。中身を見たら、ファイルの一覧で `index.html` を選び直します。

### 2. 絵を貼る

1 つ目の段落の次の行に、絵を表示する 1 行を足します。中見出しの前には、空いた行を 1 つ入れておきます。

```html
  <p>山のサーキット「夕暮れ峠」を、パソコンの中でもう一度走ろう。</p>
  <img src="img/toge.svg" alt="夕日の差す山の峠。二つの折り返しを抜けて、道が尾根へ登っていく" width="640" height="360">

  <h2>ここが楽しい</h2>
```

保存して動かします。段落の下に、夕日と山と道の絵が出れば正しくできています。

ファイルの住所の区切りは `/`（スラッシュ）です。`img\toge.svg` のように `\` で区切ると絵が出ず、コンソールに「見つかりません」と出ます。

### 3. 絵と説明をひとまとめにする

`<img` の行を `<figure>` と `</figure>` で囲みます。絵の次の行には、`<figcaption>` で説明を足します。

```html
  <p>山のサーキット「夕暮れ峠」を、パソコンの中でもう一度走ろう。</p>
  <figure>
    <img src="img/toge.svg" alt="夕日の差す山の峠。二つの折り返しを抜けて、道が尾根へ登っていく" width="640" height="360">
    <figcaption>夕暮れ峠（全長 1,981 m、高低差 44 m）</figcaption>
  </figure>

  <h2>ここが楽しい</h2>
```

保存して動かします。絵が少し右に寄り、絵の下に「夕暮れ峠（全長 1,981 m、高低差 44 m）」と出れば正しくできています。

## しくみ

### img 要素

img（image）は、絵を表示する要素です。中身を持たないので、終了タグはありません。1-1 で書いた meta と同じ空要素です。

| 属性 | 役目 |
|---|---|
| src | 絵のファイルの住所（source） |
| alt | 絵の中身を伝える文（alternative text） |
| width | 絵の幅 |
| height | 絵の高さ |

### ファイルの住所

`img/toge.svg` は、「index.html と同じフォルダにある img フォルダの、その中の toge.svg」という意味です。このように、今のファイルの場所から見て書いた住所を、相対パス（relative path）と呼びます。

index.html と同じフォルダにあるファイルなら、`game.html` のように名前だけで書けます。住所では、大文字と小文字、全角と半角も区別されます。

### alt の書き方

読み上げソフトは、絵の所で alt の文を読み上げます。絵のファイルが読み込めないときも、絵の代わりに alt の文が出ます。

「峠の絵」とだけ書いても、どんな景色かは伝わりません。絵を見た人が受け取る中身を、短い文で書きます。看板の alt には、夕日と二つの折り返しと、尾根へ登る道を書きました。

飾りのためだけの絵には、`alt=""` のように空の値を付けます。読み上げソフトは、その絵を読み飛ばします。

### width と height

width と height の数の単位は px（ピクセル、画面の点）です。ブラウザは、絵のファイルを読み終える前に、この大きさの場所を空けておきます。

この 2 つを書かないと、絵が読み込まれたときに、下の文が押し下げられて動きます。読んでいる途中の文が急に動くと、どこまで読んだかが分からなくなります。

### figure と figcaption

figure は、本文から切り離しても意味の通る、ひとまとまりの絵や図を表します。figcaption はその説明で、figure の中の最初か最後に置きます。

## 答え合わせ

「答え合わせ」を押すと、次の項目を確かめます。

- 峠の絵（img/toge.svg）を貼った
- 絵が読み込めている（ファイルの住所が正しい）
- 絵の中身を文字で伝える alt がある（5 文字以上）
- 絵の説明（figcaption）がある

「絵が読み込めている」が通らないときは、src の住所を 1 文字ずつ見直します。属性の値を囲む `"` が半角かどうかも確かめます。

## 変えてみよう

### 1. わざと住所を間違える

src の値を `img/touge.svg` に変えて、保存して動かしてみましょう。プレビューとコンソールは、どう変わるでしょうか。確かめたら、元の `img/toge.svg` に戻します。

:::answer
絵の代わりに、壊れた絵の印と alt の文が出ます。コンソールには「見つかりません: img/touge.svg」と出ます。alt の文は、このように絵が出ないときにも役に立ちます。
:::

### 2. 絵を半分の大きさにする

絵の幅と高さを、今の半分にしてみましょう。

:::answer
```html
    <img src="img/toge.svg" alt="夕日の差す山の峠。二つの折り返しを抜けて、道が尾根へ登っていく" width="320" height="180">
```

幅と高さを同じ割合で小さくすると、絵の形はそのままで小さくなります。試したら、640 と 360 に戻します。
:::

### 3. 説明を絵の上に出す

figcaption の行を、figure の中の最初に移してみましょう。

:::answer
```html
  <figure>
    <figcaption>夕暮れ峠（全長 1,981 m、高低差 44 m）</figcaption>
    <img src="img/toge.svg" alt="夕日の差す山の峠。二つの折り返しを抜けて、道が尾根へ登っていく" width="640" height="360">
  </figure>
```

説明が絵の上に出ます。figcaption は、figure の中の最初か最後に置けます。
:::
