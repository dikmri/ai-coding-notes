# 1-5 始めるボタン

## 場面

ゲンさんが、2 つのページをフォルダに入れてくれました。峠を走るゲームのページ `game.html` と、速度計とラップタイマーのページ `meter.html` です。どちらも、中身はまだ準備中です。

看板を読んだ子が、そのまま 2 つのページへ移れるようにする必要があります。

ミナ「それとね、作った人の名前も看板に入れたいな。でも、看板が長くなるのはいやだよ」

イコちゃん「ページを移るための文字と、押すと名前の箱が開くボタンを作りましょう」

## 今回の目標

看板から game.html と meter.html へ移れるようにします。押すと「作った人たち」の箱が開くボタンも作ります。

## 手順

### 1. 渡されたページを見る

ファイルの一覧で `game.html` を選び、「動かす」を押します。「動かす」は、エディタで開いている HTML のファイルを動かします。プレビューに「峠を走る」のページが出て、プレビューの上には `game.html` と出ます。

game.html には、`<p><a href="index.html">看板へ戻る</a></p>` という行があります。プレビューで「看板へ戻る」を押すと、看板のページに移ります。この書き方を、看板でも使います。

見終えたら、ファイルの一覧で `index.html` を選び直します。

### 2. ほかのページへ移る文字を書く

表の `</table>` と、最後の段落の間に、中見出しと 1 つの段落を足します。空いた行の位置は、次のとおりにします。

```html
  </table>

  <h2>走ってみよう</h2>
  <p><a href="game.html">峠を走る</a> <a href="meter.html">速度計とラップタイマー</a></p>

  <p>夏の終わりの祭りで、子どもたちに遊んでもらう予定です。</p>
```

2 つの `<a>` の間には、半角の空白を 1 つ入れます。

保存して動かします。下線の付いた文字が 2 つ出れば正しくできています。「峠を走る」を押すとプレビューが game.html に移り、「看板へ戻る」で看板に戻れます。

### 3. ボタンと箱を書く

`<a>` を書いた段落の次の行に、ボタンの段落と箱を足します。

```html
  <p><a href="game.html">峠を走る</a> <a href="meter.html">速度計とラップタイマー</a></p>
  <p><button type="button" popovertarget="credits">作った人たち</button></p>
  <div id="credits" popover>
    <h3>作った人たち</h3>
    <p>ゲンさん（車の動き）、ミナ（遊んで確かめる係）、そしてあなた。</p>
  </div>

  <p>夏の終わりの祭りで、子どもたちに遊んでもらう予定です。</p>
```

保存して動かします。最初は「作った人たち」のボタンだけが見えて、箱は見えません。ボタンを押すと、プレビューの真ん中に、枠で囲まれた箱が出ます。箱の外を押すか Esc キーを押すと、箱が閉じます。

`popovertarget="credits"` と `id="credits"` の `credits` は、同じつづりにします。1 文字でも違うと、ボタンを押しても箱は開きません。

## しくみ

### a 要素とリンク

a（anchor）要素は、ほかのページへ移るためのリンク（link）を作ります。href（hypertext reference）属性には、行き先のページの住所を書きます。

`game.html` は index.html と同じフォルダにあるので、名前だけで書けます。1-3 で学んだ相対パスと同じ書き方です。

### button 要素

button 要素は、押すとそのページの中で何かが起きるボタンを作ります。この課では、箱を開くボタンにしました。

### a と button の使い分け

| 押したときに起きること | 使う要素 |
|---|---|
| 別のページへ移る | a |
| 同じページの中で何かが起きる（箱を開く、計算するなど） | button |

見た目は、第 2 部の CSS でどちらもボタンらしくできます。そのため、要素は見た目で選ばず、押したときに起きることで選びます。読み上げソフトは、a を「リンク」、button を「ボタン」と読み上げます。使う人は押す前に、ページを移るのか、その場で何かが起きるのかを知ることができます。

### type="button"

button の type 属性を書かないと、送信のボタン（submit）として扱われます。入力の欄をまとめる form 要素の中にあると、押したときに入力した中身を送信します。

`type="button"` を付けると、何も送信しないボタンになります。今の看板に form はありませんが、あとで form の中に移しても困らないように付けておきます。

### popover

popover 属性を付けた要素は、開くまで表示されない箱（popover）になります。開いた箱は、ページのほかの部分より手前に表示されます。

button の popovertarget 属性に箱の id を書くと、ボタンを押すたびに箱が開いたり閉じたりします。開いた箱は、箱の外を押すか Esc キーを押すと閉じます。ここまでの動きは、JavaScript を書かずに使えます。

### id と div

id 属性は、ページの中で 1 つだけの名前を要素に付けます。同じ id を、2 つの要素に付けてはいけません。popovertarget は、この名前で箱を探します。

div（division）要素は、特別な意味を持たない入れ物です。箱のように、ひとまとめにしたいけれど合う要素がないときに使います。

箱の見出しには h3 を使いました。「走ってみよう」（h2）の中の話題なので、1 段下の h3 にします。

## 答え合わせ

「答え合わせ」を押すと、次の項目を確かめます。

- ゲームのページ（game.html）へのリンクがある
- 速度計のページ（meter.html）へのリンクがある
- 「作った人たち」のボタン（button）が、popover の箱を開く
- ボタンに type="button" が付いている

箱が開かないときは、popovertarget の値と id の値が同じかを見直します。「手本との違い」を押すと、手本と違う行が分かります。

## 変えてみよう

### 1. 箱に「閉じる」ボタンを付ける

箱の中に、箱を閉じるためのボタンを足してみましょう。ヒントは、`popovertargetaction="hide"` という属性です。

:::answer
箱の段落の次の行に足します。

```html
  <div id="credits" popover>
    <h3>作った人たち</h3>
    <p>ゲンさん（車の動き）、ミナ（遊んで確かめる係）、そしてあなた。</p>
    <button type="button" popovertarget="credits" popovertargetaction="hide">閉じる</button>
  </div>
```

`popovertargetaction="hide"` を付けたボタンは、箱を閉じるだけのボタンになります。このボタンにも `type="button"` を付けます。
:::

### 2. 速度計のページからゲームへ移る

meter.html に、game.html へ移るリンクを足してみましょう。meter.html をエディタで開いて「動かす」を押すと、プレビューに meter.html が出ます。

:::answer
「看板へ戻る」の段落の次の行に足します。

```html
  <p><a href="index.html">看板へ戻る</a></p>
  <p><a href="game.html">峠を走る</a></p>
```

game.html と meter.html は同じフォルダにあるので、行き先は名前だけで書けます。
:::
