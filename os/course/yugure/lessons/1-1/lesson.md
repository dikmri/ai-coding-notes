# 1-1 看板の骨組み

## 場面

ゲンさんのメモの続きには、こう書いてありました。

ゲンさん「夕暮れ峠は、山の上にあったサーキットだ。閉じてからは、だれも峠を走っていない。孫のミナは車が大好きなんだが、峠を走ったことが一度もないんだ」

ゲンさん「夏の終わりに、町の祭りがある。祭りで、峠を走れるゲームを子どもたちに遊ばせてやりたい。まずは会場の入口に、ゲームの看板を出してくれるかい」

今の index.html は、ゲンさんのメモのままです。看板として見せるには、題名も見出しも足りません。

イコちゃん「看板のページを、骨組みから作り直しましょう。メモの『もう一度走らせてほしい』という言葉は、看板の呼びかけの文に使います」

## 今回の目標

index.html を、祭りの看板の骨組みに書き換えます。ページ全体の入れ物、ページについての情報、見出しと段落を書きます。

## 手順

### 1. 前の中身を消す

エディタで `index.html` を開きます。Ctrl+A で全部を選び、Delete キーで消します。名前の行とあいさつの行も、ここで消えます。消しすぎたときは、Ctrl+Z で元に戻せます。

### 2. 骨組みを打つ

空になったエディタに、次のとおりに打ちます。行の頭の字下げは、Tab キーで入れられます。Tab を 1 回押すと、半角の空白が 2 つ入ります。

```html
<!DOCTYPE html>
<html lang="ja">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>夕暮れ峠をもう一度</title>
</head>
<body>
</body>
</html>
```

保存して動かします。プレビューは白いままで、コンソールにも何も出ません。画面に出す中身をまだ書いていないので、これで正しい状態です。

`<title>` と `</title>` の間の「夕暮れ峠をもう一度」は、プレビューには出ません。これはページの題名で、ブラウザではタブに表示されます。

`"` と `=` は半角で打ちます。全角の `”` で囲むと、ブラウザは値を正しく読み取れません。

### 3. 見出しと段落を書く

`<body>` と `</body>` の間に、3 行を足します。1 行目は看板の大見出しです。2 行目と 3 行目は看板の文で、2 行目はゲンさんのメモの言葉を呼びかけに書き直したものです。

```html
<body>
  <h1>夕暮れ峠をもう一度</h1>
  <p>山のサーキット「夕暮れ峠」を、パソコンの中でもう一度走ろう。</p>
  <p>夏の終わりの祭りで、子どもたちに遊んでもらう予定です。</p>
</body>
```

保存して動かします。大きな太字の見出しが出て、その下に 2 つの文が出れば正しくできています。

ファイル全体は、次のようになります。

```html
<!DOCTYPE html>
<html lang="ja">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>夕暮れ峠をもう一度</title>
</head>
<body>
  <h1>夕暮れ峠をもう一度</h1>
  <p>山のサーキット「夕暮れ峠」を、パソコンの中でもう一度走ろう。</p>
  <p>夏の終わりの祭りで、子どもたちに遊んでもらう予定です。</p>
</body>
</html>
```

## しくみ

### 要素とタグ

`<h1>` を開始タグ（start tag）、`</h1>` を終了タグ（end tag）と呼びます。終了タグには `/` が付きます。

開始タグから終了タグまでのまとまりを、要素（element）と呼びます。`<h1>夕暮れ峠をもう一度</h1>` は h1 要素です。

### 属性

`<html lang="ja">` の `lang="ja"` のように、開始タグの中に書く追加の情報を属性（attribute）と呼びます。属性は `名前="値"` の形で書きます。

`lang="ja"` は、ページの言葉が日本語だと示します。読み上げソフト（screen reader）は、この値を見て日本語の読み方で読み上げます。ブラウザの翻訳の機能も、この値を使います。

### 入れ子と head・body

要素の中には、別の要素を入れられます。これを入れ子（nesting）と呼びます。html 要素の中には、head 要素と body 要素が 1 つずつ入ります。

- head（ヘッド）: ページについての情報を書く。画面には表示しない
- body（ボディ）: 画面に表示する中身を書く

中に入れた要素を 1 段ずつ字下げすると、どの要素がどこに入っているかを読み取りやすくなります。字下げは、ページの見た目には影響しません。

### head の中身

| 書いたもの | 役目 |
|---|---|
| `<meta charset="utf-8">` | ファイルの文字の形（文字コード、character encoding）が UTF-8 だと示す。日本語が文字化けしなくなる |
| `<meta name="viewport" ...>` | スマートフォンでも、画面の幅に合わせてページを表示する |
| `<title>` | ページの題名。ブラウザのタブや履歴に出る |

viewport の指定がないと、スマートフォンのブラウザはパソコン用の広い幅でページを組み、全体を縮めて表示します。すると、文字がとても小さくなります。

meta には終了タグがありません。中身を持たない要素なので、開始タグだけで書きます。このような要素を空要素（void element）と呼びます。

### 文書の型

1 行目の `<!DOCTYPE html>` は、文書の型の宣言（doctype）です。今の HTML の決まりで読むように、ブラウザに伝えます。要素ではないので、終了タグはありません。

### h1 と p

h1 は大見出し（heading 1）です。ページの中心の話題を表すので、1 ページに 1 つだけ置きます。p は段落（paragraph）です。

## 答え合わせ

「答え合わせ」を押すと、次の項目を確かめます。

- html に lang="ja" がある
- 題名（title）が「夕暮れ峠をもう一度」
- 大見出し（h1）がちょうど 1 つ
- 段落（p）が 1 つ以上ある
- 文字の形（meta charset）と画面の幅（viewport）の指定がある

通らないときは、属性の `"` が半角か、題名の文字に打ち間違いがないかを見直します。「手本との違い」を押すと、手本と違う行が分かります。

## 変えてみよう

### 1. 段落を足す

ゲンさんの車は、最高 171 km/h で走ります。この話を、3 つ目の段落にして足してみましょう。

:::answer
2 つ目の段落の次の行に足します。

```html
  <p>夏の終わりの祭りで、子どもたちに遊んでもらう予定です。</p>
  <p>ゲンさんの車は、最高 171 km/h で走ります。</p>
```
:::

### 2. 大見出しを 2 つにする

h1 の行をもう 1 つ足して、「答え合わせ」を押してみましょう。どの項目が通らなくなるでしょうか。試したら、足した行を消しておきます。

:::answer
「大見出し（h1）がちょうど 1 つ」が通らなくなります。h1 はページの中心の話題を表すので、1 ページに 1 つにします。見出しを増やしたいときは、次の課で学ぶ中見出し（h2）を使います。
:::

### 3. 段落の途中で改行する

段落の文の途中で Enter を押して改行し、保存して動かしてみましょう。

:::answer
プレビューでは改行されず、文が続けて表示されます。改行の場所に、すき間が入ることもあります。ブラウザは、要素の中の改行を空白と同じに扱うからです。文を分けたいときは、p 要素を 2 つに分けます。
:::
