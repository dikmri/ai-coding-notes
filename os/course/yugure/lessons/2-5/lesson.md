# 2-5 重ねる

## 場面
ゲンさんが、工場の古い写真を見せてくれました。車の窓に「最高 171 km/h」と書いた札が貼ってあります。

ゲンさん「峠を走っていたころは、こうして最高速度の札を貼っていたんだ。看板の絵にも付けてくれるかい」
イコちゃん「要素は、ふつう上から順に並びます。絵の上に重ねるには、置き方（position）を変えます」

## 今回の目標
絵の中に速度の札（.meter）を足し、position を使って絵の右上に重ねます。

## 手順
### 1. 札を HTML に足す
index.html を開きます。絵のまとまりの中の `<img>` の行の下に、札の段落を 1 行足します。

```html
    <section class="hero">
      <figure class="photo">
        <img src="img/toge.svg" alt="夕日の差す山の峠。二つの折り返しを抜けて、道が尾根へ登っていく" width="640" height="360">
        <p class="meter">最高 171 km/h</p>
        <figcaption>夕暮れ峠（全長 1,981 m、高低差 44 m）</figcaption>
      </figure>
    </section>
```

保存して動かします。札の文字が、絵と説明の間に、ふつうの段落として出ます。

### 2. 絵の箱を基準にする
style.css の最後（@media の最後の `}` の下）に足します。

```css
/* 絵の上に速度の札を重ねる（position） */
.photo {
  position: relative;
  margin: 0;
}
```

保存して動かします。絵の左右のすき間が消え、絵が箱の幅いっぱいに広がります。`figure` 要素が最初から持っていた外の余白を、`margin: 0` で取ったからです。`position: relative` だけでは、見た目は変わりません。

### 3. 札を右上に重ねる
続けて、札の規則を足します。

```css
.meter {
  position: absolute;
  top: 12px;
  right: 12px;
  margin: 0;
  padding: 4px 12px;
  border-radius: 999px;
  background: rgb(0 0 0 / 0.6);
  color: #fff;
  font-weight: bold;
}
```

保存して動かします。札が絵の右上に、上と右の端から 12px 離れて重なります。半透明の黒い地に白い太字の、両端の丸い札です。説明の文字は、絵のすぐ下に戻ります。

札がページの右上の角に出たときは、`.photo` に `position: relative` が付いていません。2 の手順を見直してください。

## しくみ
### position の値
`position` は、要素の置き方を決めるプロパティです。

| 値 | 置き方 |
|---|---|
| `static` | 最初の値。HTML の順に、上から並ぶ |
| `relative` | ふつうの位置に置く。中の absolute の要素の基準になる |
| `absolute` | ふつうの並びから外し、基準の箱からの距離で置く |

### absolute の基準
ブラウザは、absolute の要素の外側にある要素を、近い順に調べます。`position` が static 以外の最初の要素が、基準の箱になります。

今回の基準は `.photo` です。`top: 12px` は「.photo の上の端から 12px」、`right: 12px` は「.photo の右の端から 12px」の意味になります。`top`・`right`・`bottom`・`left` の 4 つで、基準の箱の 4 つの辺からの距離を決めます。

基準になる要素がないときは、ページそのものが基準になります。`.photo` の relative を忘れると札がページの右上に出るのは、このためです。

### 並びから外れる
absolute の要素は、ふつうの並びから外れて、場所を取らなくなります。そのため、後ろの説明の文字は、札がなかったときの位置に置かれます。

position を決めた要素は、決めていない要素より手前に描かれます。そのため、札は絵の上に見えます。重なる順番を変えたいときは、`z-index` を使います。

### 札の見た目
- `rgb(0 0 0 / 0.6)` は、赤・緑・青の強さを 0〜255 で書き、`/` のあとに不透明さを 0〜1 で書く色です。0.6 なので、黒い地から少し絵が透けて見えます
- `#fff` は `#ffffff` の短い書き方です。赤・緑・青の 2 文字がそれぞれ同じ字のときは、1 文字ずつに縮められます
- `border-radius: 999px` のように大きな値にすると、札の左右の端が半円になります
- `margin: 0` は、段落（p）が最初から持つ上下の外の余白を取ります。残すと、札が 12px より下にずれます
- `font-weight: bold` は、文字を太くします

## 答え合わせ
- 速度の札（.meter）を絵の中に足した
- 札が absolute で、絵の箱（.photo）が relative
- 札が絵の右上に重なっている

通らないときは、札の段落が `<figure class="photo">` と `</figure>` の間にあるかを見直してください。「手本との違い」で手本と見比べることもできます。

## 変えてみよう
### 1. 札を左上に置く
札を、絵の左上に動かしてみましょう。

:::answer
`right` の行を `left` に変えます。

```css
.meter {
  position: absolute;
  top: 12px;
  left: 12px;
  margin: 0;
  padding: 4px 12px;
  border-radius: 999px;
  background: rgb(0 0 0 / 0.6);
  color: #fff;
  font-weight: bold;
}
```

確かめの「右上に重なっている」は通らなくなるので、試したら `right` に戻しておきましょう。
:::

### 2. 基準をなくすとどうなるか
`.photo` の `position: relative;` の行を消して、札がどこに出るか確かめましょう。

:::answer
札は、ページの右上の角に出ます。基準の箱がないので、ページそのものの上の端と右の端から 12px の所に置かれます。確かめたら、行を元に戻しましょう。
:::

### 3. 札をもう 1 枚重ねる
加速の札「0〜100 km/h 10.4 秒」を、最高速度の札の下に重ねてみましょう。名札は、空白で区切ると 2 つ付けられます。

:::answer
index.html の札の下に、1 行足します。

```html
        <p class="meter">最高 171 km/h</p>
        <p class="meter accel">0〜100 km/h 10.4 秒</p>
```

style.css の `.meter` の規則の下に、`.accel` の規則を足します。

```css
.accel {
  top: 52px;
}
```

2 枚目は `.meter` の見た目をそのまま使い、`top` だけを `.accel` で変えます。同じ強さのセレクタでは、後に書いた規則の値が使われます。そのため、`.accel` は `.meter` より下に書きます。
:::
