# 1-6 意味で区切る

## 場面

看板には、絵も説明も表もボタンも並びました。ただ、HTML の中では、すべての要素が body の中に同じ深さで並んでいるだけです。

イコちゃん「読み上げソフトを使う人は、どこからどこまでが看板の本体なのかを知りたいはずです。それに第 2 部では、まとまりごとに色を塗ります。まとまりが分かれていないと、色を付ける場所を選べません」

ゲンさん「祭りの看板なら、上に題を書いて、下にひと言を添えるもんだ。中身は真ん中だな。いちばん上には、主催の『とんぼ整備工場』の名前も入れてくれるかい」

## 今回の目標

看板を、ページの頭・本体・終わりと、話題ごとのまとまりに分けます。第 2 部で色を塗るときに使う名札も付けます。

## 手順

この課では、今ある行を新しい要素で囲みます。囲んだ中の行は、字下げを 1 段深くします。字下げはページの見た目に影響しませんが、手本とそろえておくと「手本との違い」で違いを探しやすくなります。行の頭で Tab キーを押すと、空白が 2 つ入ります。Shift+Tab で、空白を 2 つ消せます。

### 1. ページの頭（header）を作る

`<body>` の次の行から、1 つ目の段落までを `<header>` と `</header>` で囲みます。大見出しの上には、主催の名前の段落を足します。

```html
<body>
  <header>
    <p class="host">とんぼ整備工場 presents</p>
    <h1>夕暮れ峠をもう一度</h1>
    <p>山のサーキット「夕暮れ峠」を、パソコンの中でもう一度走ろう。</p>
  </header>
```

`class="host"` は、この段落に「host」という名札を付ける書き方です。名札の使い道は、しくみで説明します。

保存して動かします。大見出しの上に「とんぼ整備工場 presents」と出れば正しくできています。

### 2. 本体（main）と終わり（footer）で囲む

`</header>` の次に、空いた行と `<main>` を足します。

```html
  </header>

  <main>
```

ページのいちばん下では、「作った人たち」の箱の `</div>` の次の行に `</main>` を足します。最後の段落は、`<footer>` と `</footer>` で囲みます。

```html
  </main>

  <footer>
    <p>夏の終わりの祭りで、子どもたちに遊んでもらう予定です。</p>
  </footer>
</body>
```

保存して動かします。見た目は変わりません。

### 3. 絵のまとまりを作る

`<main>` の次の figure を、`<section class="hero">` と `</section>` で囲みます。figure には、`photo` という名札を付けます。

```html
  <main>
    <section class="hero">
      <figure class="photo">
        <img src="img/toge.svg" alt="夕日の差す山の峠。二つの折り返しを抜けて、道が尾根へ登っていく" width="640" height="360">
        <figcaption>夕暮れ峠（全長 1,981 m、高低差 44 m）</figcaption>
      </figure>
    </section>
```

### 4. 楽しい所と操作のまとまりを作る

「ここが楽しい」と「操作」の見出しから、それぞれの箇条書きと表までを、section で囲みます。箇条書きの ul には、`cards` という名札を付けます。まとまりとまとまりの間には、空いた行を 1 つ入れます。

```html
    <section class="features">
      <h2>ここが楽しい</h2>
      <ul class="cards">
        <li><strong>本物の峠</strong>を、上から見て走れる</li>
        <li>ゲンさんの車は<em>最高 171 km/h</em></li>
        <li>周回の時間を測って、<strong>最速の記録</strong>に挑める</li>
      </ul>
    </section>

    <section class="controls">
      <h2>操作</h2>
      <table>
        <caption>キーボードの操作</caption>
        <thead>
          <tr><th scope="col">キー</th><th scope="col">動き</th></tr>
        </thead>
        <tbody>
          <tr><td><kbd>↑</kbd></td><td>アクセル</td></tr>
          <tr><td><kbd>↓</kbd></td><td>ブレーキ</td></tr>
          <tr><td><kbd>←</kbd> <kbd>→</kbd></td><td>ハンドル</td></tr>
          <tr><td><kbd>Enter</kbd></td><td>始める・もう一度</td></tr>
        </tbody>
      </table>
    </section>
```

### 5. 走ってみようのまとまりを作る

「走ってみよう」の見出しから箱の `</div>` までを、section で囲みます。2 つの a には、`button` という名札を付けます。

```html
    <section class="start">
      <h2>走ってみよう</h2>
      <p><a class="button" href="game.html">峠を走る</a> <a class="button" href="meter.html">速度計とラップタイマー</a></p>
      <p><button type="button" popovertarget="credits">作った人たち</button></p>
      <div id="credits" popover>
        <h3>作った人たち</h3>
        <p>ゲンさん（車の動き）、ミナ（遊んで確かめる係）、そしてあなた。</p>
      </div>
    </section>
  </main>
```

### 6. 保存して動かす

保存して動かします。増えたのは、いちばん上の「とんぼ整備工場 presents」の行だけで、ほかの見た目は前の課と同じです。リンクとボタンと箱が、前の課と同じに動けば正しくできています。

## しくみ

### 意味で区切る要素

| 要素 | 意味 | この看板で入れたもの |
|---|---|---|
| header | ページの頭 | 主催の名前、大見出し、呼びかけの文 |
| main | ページの本体。1 ページに 1 つだけ置く | 4 つのまとまり |
| section | 話題ごとのまとまり | 絵、楽しい所、操作、走ってみよう |
| footer | ページの終わり | 祭りのひと言 |

これらの要素には、特別な見た目がありません。ブラウザは、中の要素を上から順に表示するだけです。要素を足しても見た目が変わらなかったのは、このためです。これらの要素は、ページのどこが何なのかという意味を表すために使います。

### 目印（landmark）

読み上げソフトは、header・main・footer を、ページの中の目印（landmark）として扱います。読み上げソフトには、目印へ一度に移る操作があります。main があれば、使う人は看板の頭を飛ばして、本体からすぐに読めます。

### section と div

section は、話題ごとのまとまりを表します。ふつうは、先頭に見出しを置きます。絵のまとまり（hero）には見出しがありませんが、figcaption が絵の中身を説明しています。

1-5 で使った div は、意味を持たない入れ物でした。話題のまとまりには section を使い、合う要素がないときだけ div を使います。

### 名札（class）

class 属性は、要素に名札を付けます。第 2 部の CSS では、`.cards` のように名札の名前で要素を選び、色や大きさを決めます。

- 1 つの名札を、いくつの要素に付けてもかまいません。2 つの a には、どちらも `button` の名札を付けました
- 1 つの要素に、いくつも名札を付けられます。`class="start highlight"` のように、半角の空白で区切ります
- 名札の名前には、半角の英字と数字と `-` を使います。空白は区切りになるので、名前の中には入れません

1-5 で学んだ id は、ページの中で 1 つだけの名前でした。class は、同じ名前をいくつもの要素に付けられる所が違います。

名札の名前は、見た目より役目で付けます。`red` のように色で名付けると、あとで色を変えたときに名前と合わなくなります。`cards` や `photo` のように役目で名付けると、色を変えても名前はそのまま使えます。

### a に付けた button の名札

`<a class="button">` は、第 2 部でボタンのような見た目にするための名札です。押すと別のページへ移るので、要素は a のままにします。1-5 で学んだ使い分けのとおりです。

## 答え合わせ

「答え合わせ」を押すと、次の項目を確かめます。

- ページの頭（header）に大見出しがある
- 中身の本体（main）がちょうど 1 つ
- まとまり（section）が 3 つ以上あり、それぞれに見出しか絵がある
- ページの終わり（footer）がある
- 名札（class）が付いている（第 2 部で色を塗るときに使う）

通らないときは、開始タグと終了タグが組になっているかを見直します。特に `</section>` と `</main>` の数と場所を確かめます。「手本との違い」を押すと、手本と違う行が分かります。

すべての項目が通ると、看板が OS の「作ったアプリ」に「夕暮れ峠の看板」という名前で登録されます。デスクトップから、看板をいつでも開けます。

## 変えてみよう

### 1. 呼びかけの文に名札を付ける

header の中の呼びかけの段落に、`lead` という名札を付けてみましょう。

:::answer
```html
    <p class="lead">山のサーキット「夕暮れ峠」を、パソコンの中でもう一度走ろう。</p>
```

見た目は変わりません。第 2 部で `.lead` を選ぶと、この段落だけの文字の大きさや色を決められます。
:::

### 2. 1 つの要素に 2 つの名札を付ける

走ってみようのまとまり（`class="start"`）に、もう 1 つ `highlight` という名札を足してみましょう。

:::answer
```html
    <section class="start highlight">
```

名札と名札の間は、半角の空白で区切ります。この section には、start と highlight の 2 つの名札が付きます。
:::

### 3. main を 2 つにする

`</footer>` の次の行に `<main></main>` を足して、「答え合わせ」を押してみましょう。どの項目が通らなくなるでしょうか。試したら、足した行を消しておきます。

:::answer
「中身の本体（main）がちょうど 1 つ」が通らなくなります。main はページの本体を表すので、1 ページに 1 つだけ置きます。main が 1 つなら、読み上げソフトで本体へ移ったときの行き先も 1 つに決まります。
:::
