# 4-1 キャンバスに描く

## 場面

看板には「峠を走る」ボタンがあります。でも、押した先に峠はまだありません。
ミナ「ボタンはあるのに、走る道がどこにもないよ！」
ゲンさん「文字と表だけでは、道も車も描けないな。絵を描く場所が要る」
イコちゃん「ゲームのページ `game.html` を用意しました。中には、絵を描くための板が 1 枚あります。そこに峠を描いてみましょう」

## 今回の目標

キャンバス（canvas）に、草と道と車を四角で、太陽を丸で描きます。

## 手順

### 1. キャンバスのあるページを開く

この課の始めに、`game.html`・`game.css`・`game/main.js` の 3 つのファイルが増えています。ファイルの一覧で `game.html` を開くと、`main` の中に次の 1 行があります。

```html
<canvas id="screen" width="960" height="600">上から見た峠と、走る車の絵</canvas>
```

`canvas` 要素は、JavaScript で絵を描くための板です。`width` と `height` は、板の横と縦の画素の数です。タグの間の文は、キャンバスを表示できないときに使われる説明です。`head` の中の `script` の行が、`game/main.js` を読み込みます。

「動かす」を押します。緑色の横長の四角が見えれば正しいです。この緑は `game.css` で付けた背景の色で、まだ何も描いていません。JS や CSS のファイルを開いているときも、作業場はこの課のページ（`game.html`）を動かします。

### 2. 描く道具を取り出して、草を塗る

`game/main.js` を開きます。1 行目のコメントの下に、空の行を 1 つあけて、次のコードを書きます。

```js
const canvas = document.querySelector('#screen');
const context = canvas.getContext('2d');

// 草: 画面いっぱいの四角
context.fillStyle = '#3f5a33';
context.fillRect(0, 0, canvas.width, canvas.height);
```

保存して動かします。草の色は背景と同じなので、見た目は変わりません。塗れたかを確かめるには、`'#3f5a33'` を一度 `'tomato'` に変えて保存します。四角が赤っぽくなれば、JavaScript で塗れています。確かめたら `'#3f5a33'` に戻します。

`getContext('2D')` のように大文字で書くと、描く道具を受け取れません。コンソールに `Cannot set properties of null` と出たら、`'2d'` が小文字かを見直します。

### 3. 道と車を四角で描く

草のコードの下に、空の行を 1 つあけて続けます。

```js
// 道: 灰色の太い四角
context.fillStyle = '#6b6560';
context.fillRect(440, 0, 80, canvas.height);

// 車: 道の上の、だいだい色の小さい四角（左上の角の位置、幅、高さ）
context.fillStyle = '#c8582a';
context.fillRect(470, 400, 20, 40);
```

保存して動かします。真ん中に灰色の縦の帯が通り、その上の少し下寄りに、だいだい色の小さい四角が見えれば正しいです。

### 4. 太陽を丸で描く

車のコードの下に、空の行を 1 つあけて続けます。

```js
// 太陽: 丸は、道筋（path）に円をかいてから塗る
context.fillStyle = '#fff1c8';
context.beginPath();
context.arc(820, 90, 40, 0, Math.PI * 2);
context.fill();
```

右上に薄い黄色の丸が出れば、この課の絵はできあがりです。

## しくみ

### キャンバスの座標

キャンバスの位置は、左上の角を (0, 0) として数えます。x は右へ行くほど増え、y は下へ行くほど増えます。数学のグラフとは y の向きが逆です。単位は画素（pixel）です。

このキャンバスは、横 960 画素、縦 600 画素です。道は x が 440 から幅 80 なので、440〜520 の帯になります。帯の真ん中の 480 は、960 のちょうど半分です。

`game.css` は、キャンバスの見た目の幅を画面に合わせて変えます。見た目の大きさが変わっても、描くときの座標は 960 × 600 のままです。

### 描く道具（context）

`canvas.getContext('2d')` は、平面の絵を描く道具を返します。この道具をコンテキスト（context）と呼びます。描く命令は、どれもコンテキストに対して出します。

| 書き方 | すること |
|---|---|
| `fillStyle = 色` | これから塗る色を決める |
| `fillRect(x, y, 幅, 高さ)` | 左上の角が (x, y) の四角を塗る |
| `beginPath()` | 新しい道筋を始める |
| `arc(x, y, 半径, 始めの角度, 終わりの角度)` | 中心 (x, y) の円の一部を道筋に足す |
| `fill()` | 道筋の内側を塗る |

あとから描いた絵は、前の絵の上に重なります。車を道より先に描くと、道に隠れて見えなくなります。

### 道筋と角度

四角でない形は、先に道筋（path）を作ってから塗ります。`beginPath` で道筋を空にし、`arc` で円の形を足し、`fill` で内側を塗ります。

`arc` の角度は、ラジアン（radian）という単位で書きます。1 周が `Math.PI * 2`（約 6.28）です。0 から `Math.PI * 2` まで回すと、1 周の丸になります。ラジアンは、4-3 で車の向きにも使います。

### 背景の色と、塗った色

`game.css` の `background` は、キャンバスの後ろに見える色です。何も描いていない画素は透明なので、後ろの緑が見えていました。答え合わせは、キャンバスの画素の色を読みます。そのため、草も `fillRect` で塗っておきます。

## 答え合わせ

- キャンバス（#screen）が 960 × 600
- 左上が草の色で塗られている（何も描かない白や透明ではない）
- 画面の真ん中の縦の帯（道）が、草と違う色
- 丸（arc）を描いた

通らないときは、手順 2〜4 のコードを読み直します。違う所が見つからないときは、「手本との違い」ボタンで手本と比べます。

## 変えてみよう

### 1. 2 台目の車

道の上の、もっと上の方に、青い車をもう 1 台描いてみましょう。

:::answer
道のコードより後ろに足します。道より先に描くと、道に隠れます。

```js
// 2 台目の車
context.fillStyle = '#2f6fb3';
context.fillRect(470, 200, 20, 40);
```
:::

### 2. 半分の丸

`arc` の終わりの角度を `Math.PI` にすると、どんな形になるでしょう。予想してから試します。

:::answer
```js
context.beginPath();
context.arc(120, 90, 40, 0, Math.PI);
context.fill();
```

下半分の丸になります。角度 0 は円の右端で、角度が増えると画面の上で右回りに進みます。0 から `Math.PI` までは、下を通って左端に着きます。`fill` は、始めと終わりを直線で結んで塗ります。
:::

### 3. 道の真ん中の点線

3-4 で使った `for...of` で、白い細い四角を道の真ん中に並べます。y を 0, 80, 160 … 560 と変えながら描きます。

:::answer
道のコードの後、車のコードの前に入れます。

```js
// 道の真ん中の点線
context.fillStyle = '#efe6da';
for (const y of [0, 80, 160, 240, 320, 400, 480, 560]) {
  context.fillRect(478, y, 4, 40);
}
```

x の 478 は、幅 4 の四角の真ん中を、道の真ん中の 480 に合わせる値です。
:::
