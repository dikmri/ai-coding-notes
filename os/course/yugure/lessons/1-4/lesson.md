# 1-4 操作の表

## 場面

ミナ「どのキーで走るのか、看板に書いておいてよ。祭りに来るのは、初めて遊ぶ子ばかりだよ」

ゲンさん「上の矢印でアクセル、下の矢印でブレーキ、左右の矢印でハンドルだ。始めるのと、もう一度走るのは Enter だな」

キーと動きの組を文で続けて書くと、どのキーが何をするのかを探しにくくなります。

イコちゃん「キーと動きを、表にして並べましょう。左にキー、右に動きを書けば、ひと目で分かります」

## 今回の目標

キーボードの操作を、見出しの付いた表にして看板に足します。

## 手順

### 1. 表の枠と見出しの行を書く

箇条書きの `</ul>` の次の行に、中見出しと表を足します。最後の段落との間は、空いた行を 1 つ入れます。

```html
  </ul>
  <h2>操作</h2>
  <table>
    <caption>キーボードの操作</caption>
    <thead>
      <tr><th scope="col">キー</th><th scope="col">動き</th></tr>
    </thead>
  </table>

  <p>夏の終わりの祭りで、子どもたちに遊んでもらう予定です。</p>
```

保存して動かします。「操作」の見出しの下に「キーボードの操作」と出て、その下に太字の「キー」と「動き」が横に並べば正しくできています。

### 2. 中身の行を書く

`</thead>` の次の行に、`<tbody>` から `</tbody>` までを足します。キーと動きの組を、1 行に 1 つずつ書きます。

```html
    </thead>
    <tbody>
      <tr><td>↑</td><td>アクセル</td></tr>
      <tr><td>↓</td><td>ブレーキ</td></tr>
      <tr><td>← →</td><td>ハンドル</td></tr>
      <tr><td>Enter</td><td>始める・もう一度</td></tr>
    </tbody>
  </table>
```

矢印は、日本語入力で「やじるし」と打って変換すると、候補に出ます。

保存して動かします。キーと動きが、見出しの下に 4 行並べば正しくできています。

### 3. キーの名前を kbd ではさむ

キーの名前を、1 つずつ `<kbd>` と `</kbd>` ではさみます。← と → は、別々にはさみます。

```html
    <tbody>
      <tr><td><kbd>↑</kbd></td><td>アクセル</td></tr>
      <tr><td><kbd>↓</kbd></td><td>ブレーキ</td></tr>
      <tr><td><kbd>←</kbd> <kbd>→</kbd></td><td>ハンドル</td></tr>
      <tr><td><kbd>Enter</kbd></td><td>始める・もう一度</td></tr>
    </tbody>
```

保存して動かします。「Enter」の文字が等幅の字体（すべての字が同じ幅の字体）に変われば、正しくできています。

## しくみ

### 表の要素

表は、いくつかの要素を組み合わせて書きます。表の 1 つ 1 つの枠を、ます（cell）と呼びます。

| 要素 | 英語の名前 | 意味 |
|---|---|---|
| table | table | 表の全体 |
| caption | caption | 表の題 |
| thead | table head | 見出しの行のまとまり |
| tbody | table body | 中身の行のまとまり |
| tr | table row | 横 1 行 |
| th | table header | 見出しのます |
| td | table data | 中身のます |

tr の中に、th か td を左から順に並べます。行を上から順に並べると、表ができます。

### 行と列と scope

横の並びを行（row）、縦の並びを列（column）と呼びます。th の scope 属性は、その見出しがどの向きのますに付くかを示します。

- `scope="col"`: その見出しの下に並ぶ列のます
- `scope="row"`: その見出しの右に並ぶ行のます

看板の「キー」と「動き」は、下に並ぶ列の見出しなので `scope="col"` です。読み上げソフトは、中身のますを読むときに、そのますの見出しも合わせて伝えます。

### 表を使う所

表は、行と列に意味がある情報を並べるために使います。「キー」と「動き」のように、同じ形の組がいくつも並ぶ情報に向いています。文や絵を画面の左右に並べたいときは、第 2 部で学ぶ CSS を使います。

### kbd

kbd（keyboard input）要素は、キーボードで押すキーや打つ文字を表します。多くのブラウザは、kbd の中の文字を等幅の字体（monospace）で表示します。

## 答え合わせ

「答え合わせ」を押すと、次の項目を確かめます。

- 表（table）に説明（caption）がある
- 見出しのます（th）が 2 つ以上あり、scope が付いている
- キーの名前を kbd で 4 つ以上書いた

通らないときは、caption が table の中に入っているかを見直します。すべての th に scope があるかも確かめます。「手本との違い」を押すと、手本と違う行が分かります。

## 変えてみよう

### 1. ゲンさんの車の表を作る

ゲンさんの車は最高 171 km/h で、0〜100 km/h の加速は 10.4 秒です。変速は 5 段です。行の頭に見出しのある表にして、操作の表の下に足してみましょう。

:::answer
```html
  <table>
    <caption>ゲンさんの車</caption>
    <tbody>
      <tr><th scope="row">最高速度</th><td>171 km/h</td></tr>
      <tr><th scope="row">0〜100 km/h</th><td>10.4 秒</td></tr>
      <tr><th scope="row">変速</th><td>5 段</td></tr>
    </tbody>
  </table>
```

見出しが行の頭にあるので、scope は `row` にします。
:::

### 2. 文の中で kbd を使う

kbd は、表の外でも使えます。最後の段落の上に、Enter の使い方を書いた段落を足してみましょう。

:::answer
```html
  <p><kbd>Enter</kbd> を押すと、何度でも走り直せます。</p>
```
:::
