# 1-2 説明を並べる

## 場面

ミナ「峠を走れるのは分かったよ。でも、何が楽しいの？ 祭りに来た子は、看板を少ししか読まないよ」

ゲンさん「楽しい所なら、いくつも言えるぞ。わしの車は、最高 171 km/h まで出るんだ」

楽しい所を 1 つの段落に全部書くと、文が長くなって読みにくくなります。

イコちゃん「楽しい所を 1 つずつ、行の頭に点の付いた形で並べましょう。大事な言葉には、印も付けておきます」

## 今回の目標

看板に中見出しと箇条書きを足し、大事な言葉に強調と強めを付けます。

## 手順

### 1. 中見出しを足す

1 つ目の段落（「山のサーキット」で始まる行）の次の行に、中見出しを足します。

```html
  <p>山のサーキット「夕暮れ峠」を、パソコンの中でもう一度走ろう。</p>
  <h2>ここが楽しい</h2>
  <p>夏の終わりの祭りで、子どもたちに遊んでもらう予定です。</p>
```

保存して動かします。大見出しより一回り小さい太字で「ここが楽しい」と出れば、正しくできています。

### 2. 箇条書きを足す

中見出しの次の行に、楽しい所を 3 つ並べます。

```html
  <h2>ここが楽しい</h2>
  <ul>
    <li>本物の峠を、上から見て走れる</li>
    <li>ゲンさんの車は最高 171 km/h</li>
    <li>周回の時間を測って、最速の記録に挑める</li>
  </ul>
  <p>夏の終わりの祭りで、子どもたちに遊んでもらう予定です。</p>
```

保存して動かします。行の頭に黒い点の付いた 3 行が、少し右に下げて表示されれば正しくできています。

`</ul>` を忘れると、その次の段落まで箇条書きの中に入り、右に下げて表示されます。

### 3. 大事な言葉に印を付ける

箇条書きの 3 行を、次のように書き換えます。「本物の峠」と「最速の記録」は `<strong>` と `</strong>` ではさみます。「最高 171 km/h」は `<em>` と `</em>` ではさみます。

```html
  <ul>
    <li><strong>本物の峠</strong>を、上から見て走れる</li>
    <li>ゲンさんの車は<em>最高 171 km/h</em></li>
    <li>周回の時間を測って、<strong>最速の記録</strong>に挑める</li>
  </ul>
```

保存して動かします。「本物の峠」と「最速の記録」が太字に、「最高 171 km/h」が斜めの字になれば正しくできています。

## しくみ

### 見出しの段

見出しの要素は、h1 から h6 までの 6 段あります。h2 は中見出しで、h1 の話題の中の小さな話題に付けます。h2 の中をさらに分けるときは h3 を使います。

見出しは、段を飛ばさずに使います。h1 の次に、いきなり h3 を置くことはしません。読み上げソフトには、見出しを順にたどって読む操作があります。見出しの段がそろっていると、ページの組み立てが伝わります。

見出しの段は、文字の大きさで選びません。話の組み立ての中で、どの深さの話題かで選びます。文字の大きさは、第 2 部で学ぶ CSS で変えられます。

### 箇条書き

ul（unordered list）は、順番のない箇条書きです。1 つ 1 つの項目は li（list item）要素で書きます。li は、ul の中に入れて使います。

順番に意味があるときは、ol（ordered list）を使います。ol の項目には、行の頭に番号が付きます。

### 強調と強め

strong 要素は、その言葉が大事だと示す強調（strong importance）です。看板では「本物の峠」と「最速の記録」に付けました。

em 要素は、声に出して読むときに強く言う所を示す強め（emphasis）です。「ゲンさんの車は最高 171 km/h」と読むとき、速さの所を強く言うので em を付けました。

多くのブラウザは、strong を太字で、em を斜めの字で表示します。ただし、太字にしたいだけのときに strong は使いません。strong と em は意味を表す要素で、見た目は第 2 部の CSS で決めます。

## 答え合わせ

「答え合わせ」を押すと、次の項目を確かめます。

- 中見出し（h2）がある
- 箇条書き（ul）に 3 つ以上の項目（li）がある
- 強調（strong）がある
- 強め（em）がある

通らないときは、`<strong>` や `<em>` の終了タグに `/` があるかを見直します。「手本との違い」を押すと、手本と違う行が分かります。

## 変えてみよう

### 1. 4 つ目の楽しい所を足す

ゲンさんの車には 5 段の変速があり、0〜100 km/h まで 10.4 秒で加速します。この話を、4 つ目の項目にしてみましょう。

:::answer
`</ul>` の前の行に足します。

```html
    <li>周回の時間を測って、<strong>最速の記録</strong>に挑める</li>
    <li><strong>5 段の変速</strong>で、0〜100 km/h まで 10.4 秒</li>
  </ul>
```
:::

### 2. 遊び方を番号付きで書く

遊ぶ順番は、順番そのものに意味があります。箇条書きの下に、遊び方を ol で書いてみましょう。

:::answer
`</ul>` の次の行に足します。

```html
  <h2>遊び方</h2>
  <ol>
    <li>スタートの合図で走り出す</li>
    <li>峠を 1 周する</li>
    <li>周回の時間を見る</li>
  </ol>
```

プレビューでは、項目の頭に 1 から順に番号が付きます。
:::
