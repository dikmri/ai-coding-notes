# 2-1 色と文字

## 場面
デスクトップに「夕暮れ峠の看板」が立ちました。ミナが開いて、首をかしげます。

ミナ「白い紙に黒い字だけだね。学校のお知らせみたいだよ！」
ゲンさん「工場の看板は、夕日みたいな赤茶色に塗ってあったな」
イコちゃん「色や文字の形は、CSS という別の言葉で決めます。看板に色を塗ってみましょう」

## 今回の目標
見た目を書くファイル style.css を作り、index.html とつなぎます。ページの背景の色、文字の色、文字の形を決めます。

## 手順
### 1. style.css を作る
作業場のファイルの一覧の上にある「新しいファイル」を押します。名前を聞く窓が開くので、欄の文字を消して `style.css` と打ち、OK を押します。

一覧に style.css が増え、エディタに空のファイルが開けば正しくできています。

### 2. index.html とつなぐ
一覧から index.html を開きます。`<head>` の中の `<title>` の行の下に、`<link>` の行を 1 行足します。

```html
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>夕暮れ峠をもう一度</title>
  <link rel="stylesheet" href="style.css">
</head>
```

保存して（Ctrl+S）、動かします（Ctrl+Enter）。style.css はまだ空なので、見た目は変わりません。

コンソールに「見つかりません」と出たら、`href` の文字とファイルの名前が違っています。`styles.css` のように 1 文字多い間違いがよくあります。

### 3. ページ全体の色と文字を決める
style.css を開き、次のように書きます。

```css
/* 看板の見た目 */
body {
  margin: 0;
  background: #fbf6ec;
  color: #2b2420;
  font-family: system-ui, sans-serif;
  line-height: 1.7;
}
```

保存して動かします。style.css を開いたままでも、「動かす」は index.html をプレビューに出します。

背景がうすいクリーム色になり、文字はこげ茶色になります。文字の形と行の間も変わります。ページの端のすき間はなくなり、見出しが窓の左の端に付きます。端のすき間は次の課で整えます。

### 4. 見出しと名札に色を塗る
`body {` から `}` までの下に、次の 3 つを足します。

```css
h1 {
  margin: 0;
  color: #c8582a;
  font-size: 2.2rem;
}

h2 {
  border-bottom: 2px solid #c8582a;
}

.host {
  margin: 0;
  letter-spacing: 0.1em;
}
```

保存して動かします。大見出しが赤茶色の大きな字になります。中見出しの下には赤茶色の線が引かれます。「とんぼ整備工場 presents」は、字の間が少し広がります。

`.host` の先頭の点を忘れると、host という名前の要素を探すことになり、何も変わりません。

## しくみ
### CSS と規則
CSS（Cascading Style Sheets）は、ページの見た目を決める言葉です。HTML には中身とその意味を書き、CSS には色や大きさを書きます。

CSS は、規則（rule）を並べて書きます。1 つの規則は次の形です。

```css
h1 {
  color: #c8582a;
}
```

- `h1` はセレクタ（selector）です。どの要素に当てるかを決めます
- `color` はプロパティ（property）です。何を変えるかを決めます
- `#c8582a` は値（value）です。どう変えるかを決めます
- `color: #c8582a;` の 1 行を宣言（declaration）と呼びます。宣言は `{` と `}` の間に並べ、最後に `;` を付けます

`/*` と `*/` の間はコメントです。ブラウザはこの部分を読み飛ばすので、人へのメモに使えます。

### link でつなぐ
`<link rel="stylesheet" href="style.css">` は、見た目のファイルを読み込む指定です。`rel="stylesheet"` が「見た目を決めるファイル」の意味で、`href` がそのファイルの住所です。住所の書き方は、1-3 で絵の `src` に書いたものと同じです。

### セレクタの 2 つの形
| 書き方 | 選ぶ要素 | 今回の例 |
|---|---|---|
| `h1` | その名前の要素のすべて | 大見出し |
| `.host` | 名札（class）が host の要素 | 「とんぼ整備工場 presents」の段落 |

1-6 で付けた名札は、先頭に点の付いたセレクタで選びます。

### 色の書き方
`#c8582a` は、# のあとの 6 文字を 2 文字ずつに分けて読みます。前から順に、赤・緑・青の光の強さです。強さは 16 進数（0〜9 と a〜f）で書き、`00` がいちばん弱く、`ff` がいちばん強くなります。

`c8` は 200、`58` は 88、`2a` は 42 です。赤が強く青が弱いので、赤茶色になります。`#ffffff` は白、`#000000` は黒です。

`color` は文字の色を、`background` は背景を決めます。

### 文字の形と大きさ
- `font-family` は文字の形です。並べた名前を左から順に見て、そのパソコンにあるものを使います。`system-ui` はパソコンの画面に使われている文字、`sans-serif` は飾りのない形（ゴシック体）の仲間です
- `font-size: 2.2rem` の `rem` は、ページの基本の文字の大きさの何倍かを表します。基本はふつう 16px なので、35.2px になります
- `line-height: 1.7` は、行の高さを文字の大きさの 1.7 倍にします
- `letter-spacing: 0.1em` は、字の間を広げます。`em` はその要素の文字の大きさで、0.1em はその 1 割です

### 中の要素に伝わる
body に決めた `color` と `font-family` は、中にある段落や箇条書きにも伝わります。これを継承（inheritance）と呼びます。h1 には自分の `color` があるので、h1 だけは赤茶色になります。

`margin` は要素のまわりのすき間、`border` は枠の指定です。くわしくは次の課で学びます。

## 答え合わせ
- 見た目のファイル（style.css）をつないだ
- 大見出しの色を変えた（黒のままではない）
- ページの背景の色を変えた（白のままではない）
- 文字の形（font-family）を決めた

通らないときは、`<link>` の行の `rel` と `href` のつづりと、宣言の最後の `;` を見直してください。「手本との違い」を押すと、手本と違う行が分かります。

## 変えてみよう
### 1. 大見出しを青くする
大見出しを、夜の空のような青にしてみましょう。赤・緑・青のうち、青の 2 文字をいちばん大きくします。

:::answer
h1 の `color` を変えます。たとえば `#2f5fa8` は、青が強く赤が弱い色です。

```css
h1 {
  margin: 0;
  color: #2f5fa8;
  font-size: 2.2rem;
}
```

試したら、元の `#c8582a` に戻しておきましょう。次の課からの手順は、赤茶色で書いています。
:::

### 2. 絵の説明を小さくする
絵の下の説明（figcaption）を、少し小さい灰色の字にしてみましょう。

:::answer
style.css の最後に、figcaption の規則を足します。

```css
figcaption {
  color: #6b5e55;
  font-size: 0.9rem;
}
```
:::

### 3. 中見出しの線の形を変える
`border-bottom` の値のうち、`solid`（実線）が線の形を表します。ここを別の言葉にすると、線の形が変わります。

:::answer
`dashed` にすると短い線が並ぶ破線に、`dotted` にすると点が並ぶ点線になります。

```css
h2 {
  border-bottom: 2px dashed #c8582a;
}
```
:::
