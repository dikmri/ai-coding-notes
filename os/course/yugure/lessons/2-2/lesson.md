# 2-2 余白と箱

## 場面
ミナが看板の窓を、画面いっぱいに広げました。

ミナ「1 行が長すぎて、読むのに首を左右に動かさなきゃいけないよ」
ゲンさん「工場では、部品をひとつずつ箱に分けてしまっておく。看板も、まとまりごとに箱に入れたらどうだい」
イコちゃん「CSS では、どの要素も四角い箱として置かれます。箱の余白と枠を決めてみましょう」

## 今回の目標
中の余白（padding）・枠（border）・外の余白（margin）を使って、まとまりを箱の形にします。本体の幅に上限を決め、真ん中に置きます。

## 手順
### 1. 幅に上限を決めて、真ん中に置く
style.css の最後（`.host` の規則の下）に足します。

```css
header,
main,
footer {
  max-width: 960px;
  margin: 0 auto;
  padding: 16px;
}
```

保存して動かします。文字が窓の端から 16px 離れます。

プレビューの幅がおよそ 1000px より広いときは、中身の幅は 960px より広がらず、真ん中に寄ります。左右には、同じ幅だけ背景が見えます。

### 2. まとまりを箱にする
続けて、section の規則を足します。

```css
/* 箱: 中の余白（padding）、枠（border）、外の余白（margin） */
section {
  margin-bottom: 24px;
  padding: 16px;
  border: 1px solid #e3d6c3;
  border-radius: 12px;
  background: #ffffff;
}
```

保存して動かします。4 つのまとまりが、角の丸い白い箱になります。箱のまわりには細いうす茶色の枠が付き、箱と箱の間は 24px 空きます。

`border` の 3 つの値の間は、空白で区切ります。`1px, solid` のように `,` を入れると、枠は出ません。

### 3. 絵を箱の幅に合わせる
最後に、img の規則を足します。

```css
img {
  display: block;
  width: 100%;
  height: auto;
  border-radius: 8px;
}
```

保存して動かします。絵の角が丸くなり、絵の幅が箱の中の幅に合わせて変わります。

窓の幅を変えて、プレビューを狭くしてみましょう。絵が箱からはみ出さずに縮めば、正しくできています。絵の左右に残るすき間は、`figure` 要素が最初から持っている外の余白です。2-5 で取ります。

## しくみ
### ボックスモデル
CSS では、どの要素も四角い箱として置かれます。箱は内側から順に、次の 4 つの層でできています。この考え方をボックスモデル（box model）と呼びます。

| 層 | 名前 | 今回の section の値 |
|---|---|---|
| 中身 | content | 見出しや表 |
| 中の余白 | padding | 16px |
| 枠 | border | 1px |
| 外の余白 | margin | 下だけ 24px |

padding は枠の内側のすき間で、箱の背景の色が付きます。margin は枠の外側のすき間で、箱の背景の色は付きません。外側にある要素の背景が見えます。

### 値の数と向き
`padding: 16px` のように値が 1 つなら、上下左右がすべて 16px です。値が 2 つなら「上下」「左右」の順、4 つなら「上」「右」「下」「左」の順です。

`margin: 0 auto` は、上下が 0、左右が `auto` です。`margin-bottom` のように向きを名前に入れると、その向きだけを決められます。

### 真ん中に置くしくみ
`max-width: 960px` は、中身の幅の上限です。そこに左右の padding が 16px ずつ足されるので、箱の幅はいちばん広くて 992px です。

左右の margin を `auto` にすると、ブラウザは余った幅を左右に同じだけ分けます。そのため、箱は真ん中に来ます。プレビューが箱より狭いときは余りがないので、左右の margin は 0 になります。

### 枠と角
`border: 1px solid #e3d6c3` は、枠の太さ・線の形・色の順に書きます。`border-radius` は角の丸みの大きさです。

### 絵の大きさ
`width: 100%` は、外側の箱の中身と同じ幅にする指定です。`height: auto` にすると、高さは絵の縦と横の比から決まります。この絵は 640 と 360 の比です。

img は、最初は文字と同じ行の中に置かれます。そのため絵の下に、g や y の下に出る部分のためのすき間が残ります。`display: block` にすると、絵は 1 つの箱として置かれ、このすき間が消えます。

### いくつかのセレクタに同じ規則
`header, main, footer` のように `,` で区切ると、3 つの要素に同じ規則を当てられます。

## 答え合わせ
- まとまり（section）に中の余白（padding）がある
- まとまりに枠（border）がある
- まとまりの下に外の余白（margin）がある
- 本体の幅に上限（max-width）があり、真ん中に寄っている

通らないときは、`section` の規則と `header, main, footer` の規則のつづりを見直してください。`,` と `;` の打ち間違いも多いので、「手本との違い」で手本と見比べましょう。

## 変えてみよう
### 1. 中の余白を広げる
section の `padding` を 32px にして、箱の中がどう変わるか確かめましょう。

:::answer
```css
section {
  margin-bottom: 24px;
  padding: 32px;
  border: 1px solid #e3d6c3;
  border-radius: 12px;
  background: #ffffff;
}
```

枠と中身の間が広がり、箱の白い部分が増えます。箱と箱の間（margin）は変わりません。試したら 16px に戻しておきましょう。
:::

### 2. 1 行を短くする
本体の幅の上限を 720px にして、1 行の長さを短くしてみましょう。

:::answer
```css
header,
main,
footer {
  max-width: 720px;
  margin: 0 auto;
  padding: 16px;
}
```

プレビューが広いときに、左右の背景が広くなり、1 行が短くなります。試したら 960px に戻しておきましょう。
:::

### 3. 箱の左に太い線を引く
枠は `border-left` のように、1 つの向きだけにも引けます。section の左だけに、赤茶色の太い線を足してみましょう。

:::answer
section の規則の中に、1 行足します。`border` の行より下に書くと、左の線だけが新しい値に変わります。

```css
section {
  margin-bottom: 24px;
  padding: 16px;
  border: 1px solid #e3d6c3;
  border-left: 6px solid #c8582a;
  border-radius: 12px;
  background: #ffffff;
}
```
:::
